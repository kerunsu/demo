# 语音对话黑盒对接 — 一页交接说明（给对方）

> 你只需维护本目录；**不必**阅读儿童端前端、课程逻辑或我方评估代码。  
> 接口细节见 [CONTRACT.md](./CONTRACT.md)；英文速查见 [HANDOFF.md](./HANDOFF.md)。

---

## 1. 我们要什么（黑盒边界）

| 我方每次给你 | 你每次还我 |
|--------------|------------|
| 儿童本轮 **合并音频**（如 webm，base64） | **`replyText`**：展示给儿童的回复文案 |
| **页面文字描述**（结构化字段 + `narrative` 一段话） | **`replyAudio`**（可选）：回复语音 base64 + mimeType |
| **页面截图**（JPEG，可能为 `null` 并带原因） | 失败时 `ok: false` + `error.code` |
| **多轮 history**（最近若干轮 user/assistant 文本） | 可选 `metadata`（provider、latency 等） |

**你不需关心：** 我方如何做注意力/情绪/表达性语言评分、原始音频是否落盘、浏览器 STT。  
**我方不传：** 浏览器转写结果；若你需要文本，请自行 STT 或读 `pageContext.text`。

**部署无限制：** 可用本目录参考服务，也可自建任意语言/框架的独立 HTTP 服务，只要满足契约。

---

## 2. 你只需改的文件（1～3 个）

| 文件 | 作用 |
|------|------|
| **`partner.env`** | 从 `partner.env.example` 复制；配置鉴权、用哪些页面字段、内部 STT/LLM/TTS 地址 |
| **`partner_impl.py`** | 实现 `process_turn(payload) -> dict`（若用我方 `reference_server.py` 壳） |
| **`prompts/system.txt`** | 可选：系统提示词 |

稳定壳（一般不改）：`reference_server.py`、`CONTRACT.md`。

---

## 3. HTTP 契约（唯一业务接口）

- **健康检查：** `GET /health` → `{ "status": "ok" }`
- **对话回合：** `POST /v1/voice-turn`  
  - 鉴权（若配置）：请求头 `x-voice-partner-key: <与 partner.env 中 PARTNER_API_KEY 一致>`
  - 成功：`{ "ok": true, "replyText": "...", "replyAudio": { "base64", "mimeType" } }`
  - 失败：`{ "ok": false, "error": { "code", "message" } }`

我方后端代理调用你的服务，儿童端**不直连**你的 URL。

---

## 4. 你的配置项（`partner.env`）

```env
CONTEXT_INPUT_MODE=both   # text | image | both — 我方始终上传 text+截图，你只选读哪些
STT_MODE=audio            # audio | text_only_fallback | none — 与我方浏览器 STT 无关
LLM_HTTP_URL=             # 可选：你自己的 LLM HTTP
TTS_HTTP_URL=             # 可选：你自己的 TTS HTTP
PARTNER_API_KEY=...       # 与我方 VOICE_PARTNER_API_KEY 对齐
```

## 5. 本地联调（5 分钟）

**你方：**

```powershell
copy tools\voice-partner\partner.env.example tools\voice-partner\partner.env
# 编辑 partner.env / partner_impl.py
python tools\voice-partner\reference_server.py
# 默认 http://127.0.0.1:9876
```

**我方（`backend/.env`）：**

```env
VOICE_DIALOG_PROVIDER=partner
VOICE_PARTNER_BASE_URL=http://127.0.0.1:9876
VOICE_PARTNER_API_KEY=dev-partner-key
VOICE_PARTNER_FALLBACK=none
```

**自检：**

```bash
curl http://127.0.0.1:9876/health
curl http://127.0.0.1:3001/api/voice-partner/health
```

儿童端训练页录音结束 → 应出现你的 `replyText`；有 `replyAudio` 则自动播放。

---

## 6. 联调时请提供给我方

1. 服务根地址（如 `http://内网IP:9876`）  
2. `x-voice-partner-key`（若启用）  
3. 支持的回复音频格式（建议 `audio/wav` 或 `audio/mpeg`）  
4. 预计单轮延迟与超时建议（我方默认 30s）

---

## 7. 注意事项

- **页面上下文：** 每轮都会带 `pageContext.text` 与 `pageContext.screenshot`（截图失败时为 `null`，不阻断请求）。  
- **多轮对话：** `history` 已包含；不需要可在你方忽略。  
- **失败策略：** 我方默认 **不回退** 内置规则回复（`VOICE_PARTNER_FALLBACK=none`），儿童端仅提示「对话暂时不可用」。  
- **安全：** 我方会对 `replyText` 做输出审查；请勿在响应里返回密钥或儿童隐私原文日志。  
- **默认环境：** 未改 `VOICE_DIALOG_PROVIDER` 时仍为 `rule`，不影响现有 demo；仅联调环境切 `partner`。
