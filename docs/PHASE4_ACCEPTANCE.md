## 2. 已知问题（当前版本）

1. 课程题库为内置静态数据  
   影响：不支持动态配置新题目  
   建议：下阶段接入题库配置文件或轻量后台

2. 对话为规则模板，语义理解能力有限  
   影响：复杂问句可能回复泛化  
   建议：引入可替换的 LLM Provider 接口

3. 会话和报告当前以内存为主  
   影响：服务重启后历史会话不保留  
   建议：接入 SQLite/PostgreSQL 并保留报告归档

4. 目前仅文本交互，无语音输入输出  
   影响：沉浸式互动体验仍有限  
   建议：后续加语音识别与 TTS（可选离线优先）

## 3. 下一阶段建议（优先级）

## P1（高优先）

- 数据持久化：会话/报告存储到数据库
- 对话能力升级：规则 + LLM 双路容错
- 课程配置化：题库与提示语外置

## P2（中优先）

- 语音模块：ASR + TTS
- 报告导出：JSON/PDF
- 训练日志面板：便于教研与调试

## P3（低优先）

- 个性化推荐策略
- 长期学习画像
- 多终端联动演示

## 4. 演示结论

项目已达到 MVP 目标：  
可以本地启动并完整演示儿童端闭环，支持两类课程、轻量对话与自动报告生成，具备继续迭代的清晰边界与工程基础。
