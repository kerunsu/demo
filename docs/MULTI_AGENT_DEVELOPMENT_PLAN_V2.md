# 多 Agent 开发计划 V2

当前事实：M1/M2 已完成本地检查点；M3 当前代码基线已通过 `npm test` 与 `npm run build`，可标记为 `COMPLETE_CODE`，但真实局域网双主机现场验收仍待执行。本文保留未来编码阶段的多 Agent 计划，但所有实现任务必须先满足测试、契约和文件独占规则。

## 1. 协作规则

1. 架构、领域事件、状态机、Provider 接口、报告指标等共享契约必须有单一 Owner。
2. `frontend/src/App.tsx`、`backend/src/index.ts`、`backend/src/services/sessionService.ts` 是热点文件，同一开发波次只能由一个 Agent 修改。
3. 共享契约未合并前，不得并行实现依赖它的双屏同步、语音时序或动画联动。
4. Provider 接口固定后，STT、TTS、LLM、Safety Review 的 Mock 可以并行实现；真实 provider 仍需安全评审。
5. 每个实现任务完成后必须有独立测试或 Reviewer pass。
6. 实现 Agent 不得顺手修改任务范围外文件。
7. 并行写任务优先使用独立 Git Worktree；共享文件 Owner 负责合并顺序。
8. 禁止写入真实 API Key，禁止默认发送真实儿童原始音视频到外部服务。
9. 开发阶段允许用开发人员录制、合成或明确授权的非真实儿童测试音频/文本测试云端 STT/TTS；最终产品儿童数据上云仍需负责人和隐私流程确认。

## 3. 当前可立即进入的 M1/M2 顺序

1. `M1-001` 后端 API 自动化测试基线。
2. `M1-002` 前端构建与最小页面测试。
3. `M1-003` 当前训练闭环 E2E 测试。
4. `M1-004` 与 `M1-005` 领域事件和状态机契约。
5. `M1-006` Provider 和 Mock 契约。
6. `M1-007` Animation Adapter 契约。
7. `M1-008` 根级测试命令与 Fixture 规范。
8. M2 后端可测试性拆分。
9. M2 后端服务职责拆分。
10. M2 前端热点逻辑拆分。
11. M2 `/child` 和 `/robot` 页面壳。

## 4. 当前绝对不能开始的任务

- 写入真实 API Key。
- 默认上传真实儿童原始音频、原始视频、连续摄像头画面或原始图像。
- 将开发阶段授权测试音频上云误解释为最终产品儿童数据上云已获批。
- 将浏览器 `SpeechRecognition` 当作已经满足 M4 本地 STT 的正式主链路，除非能证明完全本地运行。
- 在没有本地脱敏与审核前发送儿童文本到外部大模型。
- 无审核直接播放或展示大模型输出。
- 将演示报告描述为正式专业或临床评估。
- 让大模型自由生成核心分数。
- 在事件契约未固定前开发双屏同步实现。
