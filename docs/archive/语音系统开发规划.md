## 1. 需求分析

### 1.1 当前问题
- 语音路径硬编码在 `Course.question_audio`、`Course.praise_audio`、`CourseItem.hint_audio` 字段
- 增删改语音需要修改数据库记录
- 同一语义只能播放固定的一条语音，缺乏变化
- 无法支持独立的语音互动课程（问候、日常对话等）

### 1.2 目标需求
| 需求类型 | 描述 |
|---------|------|
| **灵活性** | 同一语义支持多个变体随机播放（如5种不同的表扬语） |
| **可扩展** | 轻松添加新语音，无需修改数据库结构 |
| **分类管理** | 按用途分类：表扬、提示、提问、问候、回应等 |
| **上下文感知** | 根据课程类型、学生状态选择合适的语音 |
| **统一接口** | 前后端通过统一协议触发语音播放 |

### 1.3 使用场景
1. **课程内语音**：提问、提示、表扬（现有功能增强）
2. **日常互动语音**：问候、再见、鼓励
3. **拟声课程**：动物叫声匹配
4. **未来扩展**：纯语音对话课程、情感回应

### 2.2 核心组件说明

| 组件 | 位置 | 职责 |
|------|------|------|
| **AudioRegistry** | 服务端 | 管理语音清单，提供查询接口 |

│   服务端    │ ──────────────────► │   儿童端    │

│             │   audio_status      │             │

       │
       │ 状态同步
       ▼
┌─────────────┐
│   教师端    │  显示播放状态 + 停止按钮
│ (React/JS)  │
└─────────────┘

       ▼
┌─────────────┐     stop_audio      ┌─────────────┐

```

**事件定义**:
| 事件名 | 方向 | 载荷 | 说明 |
|--------|------|------|------|
| `play_audio` | 服务端→儿童端 | `{file, priority, audioId}` | 播放语音 |
| `stop_audio` | 服务端→儿童端 | `{immediate: bool}` | 停止播放 |
| `audio_status` | 儿童端→服务端 | `{status, audioId, file}` | 播放状态回调 |

## 4. 数据模型设计

### 4.1 方案对比

| 方案 | 优点 | 缺点 | 推荐场景 |
|------|------|------|---------|
| **YAML配置文件** | 简单、版本控制友好、易修改 | 运行时修改需重启 | 语音相对固定 |
| **数据库表** | 动态管理、可关联其他表 | 增加复杂度 | 需要运行时管理 |
| **混合方案** | 灵活 | 需要同步 | 渐进式迁移 |

**推荐**: 先用 YAML 配置文件，后续可扩展为数据库

# app/audio/controller.py

class AudioController:
    """语音播放控制器 - 管理播放状态和控制命令"""
    
    def __init__(self, socketio):
        self.socketio = socketio
        self._session_status: Dict[str, AudioStatus] = {}  # session_id -> 状态
    
    def stop_audio(self, session_id: str, immediate: bool = True):
        """
        停止指定会话的语音播放
        
        Args:
            session_id: 会话ID
            immediate: 是否立即停止（True=立即，False=播完当前）
        """
        self.socketio.emit('stop_audio', {
            'immediate': immediate,
            'timestamp': time.time()
        }, room=session_id)
        
        # 更新状态
        if session_id in self._session_status:
            self._session_status[session_id].status = 'stopped'
    
    def on_audio_status(self, session_id: str, data: dict):
        """
        处理儿童端播放状态回调
        
        data: {
            'status': 'playing' | 'ended' | 'error',
            'audioId': str,
            'file': str,
            'timestamp': float
        }
        """
        status = AudioStatus(
            session_id=session_id,
            status=data.get('status'),
            current_audio_id=data.get('audioId'),
            current_file=data.get('file'),
            updated_at=data.get('timestamp')
        )
        self._session_status[session_id] = status
        
        # 转发给教师端
        self.socketio.emit('audio_status_update', status.to_dict(), room=session_id)
    
    def get_status(self, session_id: str) -> Optional[AudioStatus]:
        """获取会话的当前播放状态"""
        return self._session_status.get(session_id)
```

### 6.2 Socket 事件处理

```javascript
// static/js/child.js 新增

// 监听新的语音播放事件
socket.on('play_audio', (payload) => {
    if (!payload || !payload.file) return;
    
    const { file, priority = 0, interrupt = false, audioId, sequence } = payload;
    
    if (sequence && Array.isArray(sequence)) {
        // 序列播放
        audioPlayer.playSequence(
            sequence.map(s => s.file),
            payload.interval || 500
        );
    } else {
        // 单个播放
        audioPlayer.play(file, { priority, interrupt, audioId });
    }
});

// 监听停止播放事件
socket.on('stop_audio', (payload) => {
    const { immediate = true } = payload || {};
    audioPlayer.stop(immediate);
    
    // 回报状态
    socket.emit('audio_status', {
        status: 'stopped',
        audioId: audioPlayer.currentAudioId,
        timestamp: Date.now()
    });
});

// 播放状态回调
audioPlayer.onStatusChange = (status, audioId, file) => {
    socket.emit('audio_status', {
        status: status,  // 'playing' | 'ended' | 'error'
        audioId: audioId,
        file: file,
        timestamp: Date.now()
    });
};
```
