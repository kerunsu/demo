#### 2.4 播放和控制
1. **自动播放**: 页面加载后应自动开始播放第一个子项

3. 系统分析 → 匹配成功 → 自动播放表扬语音（"你真棒！"）
4. 教师可随时点击"停止"按钮中断语音

## 常见问题排查

### 问题1：没有声音
**检查**:
1. 浏览器控制台是否有JavaScript错误
2. 网络标签页，音频文件HTTP状态是否200
3. 浏览器/系统音量是否静音
4. 文件路径是否正确（应包含 `/static/` 前缀）

### 问题2：控制面板不显示
**检查**:
1. Socket.IO 是否连接（左侧面板绿色圆点）
2. 控制台是否收到 `audio_status_update` 事件
3. `audioStatus.isPlaying` 状态是否为 true

### 问题3：停止按钮无效
**检查**:
1. `currentSessionId` 是否已设置
2. 控制台是否有 "⏹️ 发送停止音频请求" 日志
3. 后端是否收到 `stop_audio` 事件
4. 儿童端是否收到 `stop_audio` 事件

### 问题4：音频播放错误
**检查后端日志**:
```
2026-01-18 XX:XX:XX - audio_events - INFO - 收到语音状态更新 - 会话: xxx, 状态: error, 条目: xxx
```
**解决方法**:
- 检查文件路径是否存在
- 确认文件格式（应为 .mp3）
- 检查浏览器是否支持该音频格式
