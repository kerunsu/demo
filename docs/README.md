# 文档索引

协作规范的唯一入口是根目录 [`AGENTS.md`](../AGENTS.md)。本文只负责索引当前事实文档。

根目录以 `README.md` 作为项目介绍入口、以 `AGENTS.md` 作为协作入口。`DEMO_SYNC.md` 是完整版本向 Demo 同步、独立部署和发布验收的事实文档。运行所需的 `.env`、依赖清单、`pytest.ini` 和 `start_server.ps1` 必须位于根目录。

## 当前有效文档

- `DEMO_SYNC.md`：Demo 产品边界、上游同步矩阵、全新拉取和发布验收。
- `ARCHITECTURE.md`：模块边界与依赖方向。
- `COLLABORATION.md`：旧链接兼容入口，规则以根目录 `AGENTS.md` 为准。
- `CONTRACT.md`：HTTP、Socket 和 Demo 禁用能力契约。
- `CONFIGURATION.md` / `ENVIRONMENT.md`：配置和部署。
- `OPERATIONS.md`：启动、监控、备份、升级与排障。
- `TESTING.md`：测试与发布门禁。

历史阶段、机械动作、Robot Runtime 和社交课程计划由完整版本的 Git 历史保存，不在 Demo 文档树重复保留。屏幕表情已作为 Demo 正式能力恢复；当前边界以 `DEMO_SYNC.md` 为准。
