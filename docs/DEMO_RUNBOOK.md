# 演示手册（启动到报告）

> 环境配置见 [`ENVIRONMENT.md`](ENVIRONMENT.md)；完整上手见 [`ONBOARDING.md`](ONBOARDING.md)。

## 1. 演示目标

在本地一次性演示完整闭环：

1. 儿童进入系统
2. 选择课程并完成训练
3. 训练中进行一句自然语言交互
4. 自动生成并查看评估报告

## 2. 演示前准备（1 分钟）

- 确保已安装 Node.js 18+（建议 20+）
- 根目录执行依赖安装：

```bash
npm install
npm --prefix backend install
npm --prefix frontend install
```

## 3. 启动步骤（30 秒）

在项目根目录执行：

```bash
npm run dev
```

访问地址：

- 儿童端：`http://127.0.0.1:5173/child`
- 机器人屏：`http://127.0.0.1:5173/robot`（可选，双屏演示）
- 监控台：`http://127.0.0.1:5173/server`（可选）
- 后端 API：`http://127.0.0.1:3001`

### M3 局域网双主机启动

当前事实：M3 支持通过环境变量配置机器人主机访问独立后端主机。

后端主机示例：

```bash
BACKEND_HOST=0.0.0.0 BACKEND_PORT=3001 PUBLIC_BACKEND_ORIGIN=http://<后端主机局域网IP>:3001 CORS_ORIGIN=http://<机器人主机局域网IP>:5173 npm --prefix backend run dev
```

机器人 Windows 主机示例：

```bash
VITE_API_BASE_URL=http://<后端主机局域网IP>:3001/api VITE_WS_URL=ws://<后端主机局域网IP>:3001/ws npm --prefix frontend run dev
```

访问地址：

- 儿童屏：`http://127.0.0.1:5173/child`
- 机器人表情屏：`http://127.0.0.1:5173/robot`

Windows 防火墙验收：

- 后端主机允许 Node.js 或端口 `3001` 的局域网入站连接。
- 机器人主机浏览器能访问 `http://<后端主机局域网IP>:3001/api/health`。
- 机器人主机两个浏览器窗口分别打开 `/child` 和 `/robot`。
- 机器人屏点击“启用声音”后再开始训练，可验证 Mock 语音完成回执；未点击时后端会走超时降级。
- 断开网络或关闭机器人屏后重新打开 `/robot`，应通过 session snapshot 和 WebSocket 重连恢复当前会话事件。

当前限制：真实双主机人工验收需要现场网络环境，本地自动化已覆盖 WebSocket 事件、GIF 请求、Mock TTS 回执和下一题事件。

## 4. 标准演示流程（建议顺序）

### Step A：欢迎页

- 输入儿童昵称（例如“小明”）
- 点击“开始训练”

预期结果：进入课程选择页。

### Step B：课程选择页

- 选择“配对训练”或“排序训练”
- 点击“开始所选课程”

预期结果：进入课程进行页并显示第 1 题。

### Step C：课程进行页

- 先故意答错同一题两次
- 观察系统提示语是否出现
- 再答对并观察自动进入下一题

预期结果：

- 即时反馈正常（正确/错误）
- 错误两次触发提示
- 正确后自动推进下一题

### Step D：轻量对话

- 在聊天输入框发送一句话（例如“我有点不会”）

预期结果：系统返回简短鼓励/提示回应。

### Step E：完成课程与报告

- 完成全部题目
- 等待系统自动生成报告并跳转报告页

预期结果：报告字段完整展示（见下一节）。

## 5. 报告页重点检查项

- 完成时间
- 总题数/正确数/正确率
- 平均响应时长
- 错误类型统计（`mismatch`/`wrong_order`）
- 对话摘要（消息数量、关键词、高亮）

## 6. 演示失败时快速排查

1. 页面打不开

- 使用 `127.0.0.1` 而非 `localhost`
- 检查前端端口 `5173` 是否被占用

1. 提交答案失败

- 检查后端是否在 `127.0.0.1:3001` 正常运行
- 查看后端终端日志中的请求错误

1. 报告未生成

- 确认是否已完成全部题目
- 检查 `/api/report/:sessionId/generate` 返回信息
