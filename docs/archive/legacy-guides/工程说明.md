# 工程说明（交接导读）

本文档是**根目录下的统一导读**：用一条由浅入深的路径，把仓库里分散的说明串起来，便于交接与自学。更细的专题仍以 `docs/` 与 [项目结构说明.md](项目结构说明.md) 为准。

---

## 一、项目是什么（3 分钟）

- **定位**：教育训练系统——教师端选学生与课程，儿童端接收指令、展示课程资源并上传音视频流；服务端负责会话、录制、可插拔分析（姿态/语音等）、反馈与可选机械臂。
- **技术栈**：Python **Flask + Flask-SocketIO**，SQLite（SQLAlchemy），前端为 **Jinja 儿童端** + **`teacher_frontend`（Vite + React 教师端）**；静态资源在 `static/`。
- **入口**：`python app.py` 一键启动后端（默认 `8080`）与教师端 Vite（`5173`）；细节见下文「如何跑起来」。

## 三、如何跑起来（核对清单）

**最快**：`python scripts/bootstrap.py`（幂等：缺啥补啥；无 `app.db` 时自动播种标准库）。已配好环境再跑也会做检查，默认不覆盖 `.env` / 已有数据库。

1. Python 虚拟环境，`pip install -r requirements.txt`；若使用真实语音分析，再安装 [requirements-optional-analyzers.txt](requirements-optional-analyzers.txt)。
2. 复制 `.env.example` 为 `.env`（若使用）。
3. 数据库：`python database/seed_standard.py`（`init_db` + courses.json/CSV/配对/排序/社交导入）。仅建表也可用 `python database/init_db.py`（详见 [database/README.md](database/README.md)）。
4. 教师端首次：`cd teacher_frontend && npm ci`。
5. 一键启动：`python app.py`（同时拉起后端与教师端 Vite）。仅后端：`START_TEACHER_FRONTEND=0 python app.py`。Socket 地址见 `ControlPage.tsx` / `VITE_SOCKET_URL`。
6. 浏览器：儿童端 `http://127.0.0.1:8080/child`，教师端一般为 Vite 开发端口（如 `5173`）。

## 四、`requirements.txt` 是否完整？

- **常规运行（含 Mock 分析器）**：主文件已列出 Flask 栈、录制与视觉常用库、**`soundfile`**（真实语音分析器**模块会被加载**，顶层依赖 `soundfile`，必须安装）。
- **启用 FunASR / PyTorch 真实 ASR**：需额外安装 **torch、funasr、librosa**，已单独写在 **requirements-optional-analyzers.txt**，避免所有人被迫安装超大依赖。
- **教师端前端**：依赖在 `teacher_frontend/package.json`，与 Python 分离。
- **可选子系统**：`doll/` 为 Node，见 `doll/` 与 [docs/README_USAGE.md](docs/README_USAGE.md)。

若交接对象要「一键冻结」环境，可在干净 venv 中安装后执行 `pip freeze > requirements-lock.txt` 作为补充（非必须）。

## 五、目录结构是否清晰？改进建议

**当前合理之处**

- **`app/`**：业务代码集中，分层（`services`、`core`、`sockets`、`session` 等）可读。
- **`docs/` + `docs/archive/`**：专题与历史分离，避免根目录堆满 `.md`。
- **`tools/maintenance/`**：一次性脚本与笔记集中，避免与运行时混淆。
- **`static/`、`templates/`、`database/`**：职责直观。

**可改进（非必须，按需迭代）**

| 建议 | 说明 |
|------|------|
| 保持「一个导读入口」 | 根目录以 **README.md + 本文工程说明.md** 为双入口：README 极简，本文稍展开；细节进 `docs/`。 |
| 教师端目录 | 使用 **`teacher_frontend/`**（Vite + React），与后端分离部署。 |
| 大型二进制与课程资源 | `static/resources/` 体量可能很大，交接时说明**是否随仓库分发**或独立资源包，避免克隆困难。 |
| 配置真相源 | `app/config.py`、`config/analyzers.yaml`、`config/audio_manifest.yaml` 等并存，交接时说明**优先级**（见 ENVIRONMENT.md）。 |

总体：**结构可用于交接**；清晰度更多取决于「导读文档 + 环境可复现」，而非再拆更多文件夹。
