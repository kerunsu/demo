# 儿童 AI 安全、隐私与审核规范 V2

本文列技术风险和工程边界，不作法律合规结论。

## 1. 安全数据流

```text
儿童输入/语音转写/行为事件
  -> schema 校验
  -> PII 检测与最小化
  -> 输入审核
  -> 适龄性检查
  -> 安全上下文裁剪
  -> 主模型
  -> 输出审核
  -> 固定兜底/安全改写/通过
  -> TTS 或展示
  -> 脱敏日志
```

## 2. 输入审核

覆盖：

- 姓名、手机号、地址、学校、班级、家庭成员、精确位置、账号等敏感信息。
- 儿童危险信号：受伤、害怕、被胁迫、自伤、家庭暴力线索。
- 成人、暴力、恐吓、羞辱、歧视和不当内容。
- 医疗、心理诊断、治疗建议等越界请求。
- Prompt 注入：要求忽略规则、暴露系统提示、绕过审核。

输入审核动作：

- `allow`
- `redact_then_allow`
- `block`
- `fallback`
- `escalate_to_adult`

## 3. 输出审核

输出必须在展示或 TTS 前审核。禁止输出：

- 诊断性结论或治疗建议。
- 要求儿童提供私人信息。
- “不要告诉家长/老师”等秘密保持式互动。
- 羞辱、恐吓、强评价标签。
- 不适合 6-10 岁儿童的内容。
- 未经专业规则支持的常模、百分位和专业评估判断。

## 4. 年龄适宜性

面向 6-10 岁儿童的输出应：

- 句子短。
- 语气鼓励。
- 指令明确。
- 不使用成人化、恐吓性或诊断性词汇。
- 不展开与训练无关的开放闲聊。

## 5. 敏感信息

默认策略：

- `childName` 只作为展示昵称，不发送给主模型。
- 聊天文本进入模型前生成 `redactedText`。
- 日志只记录 PII 类型，不记录原文。
- 报告导出前支持脱敏。

## 6. 危险和不当内容

危险信号处理：

- 使用固定兜底。
- 提示请老师或家长帮助。
- 记录脱敏安全事件。
- 不让主模型自由延展危险话题。

## 7. Prompt 注入

防护：

- 主模型不接收系统密钥、内部配置或未必要的上下文。
- 用户文本作为数据而非指令处理。
- 模型输出仍需独立审核。
- Prompt 注入命中时回到训练任务或固定兜底。

## 8. 审核模型失败

审核模型失败时：

- 不默认放行。
- 使用固定兜底。
- 记录 `SAFETY_REVIEW_REJECTED` 或 `SAFETY_REVIEW_TIMEOUT`。
- 可回退确定性规则，但规则通过范围必须保守。

## 9. 审核超时

审核超时预算需配置。超时结果按失败处理，不播放或展示候选输出。

## 10. 固定兜底

兜底文本由人工预审，示例：

```text
这个内容我不能继续聊。我们可以回到当前题目，或者请老师/家长来帮忙。
```

```text
这个问题需要大人帮助。我们先暂停一下，请老师或家长来看一看。
```

```text
我不会保存或询问你的私人信息。我们继续做题吧。
```

## 11. 日志脱敏

允许记录：

- requestId、sessionHash、courseType。
- 输入长度。
- PII 类型。
- safetyAction。
- provider、latencyMs、errorCode。
- policyVersion。

禁止默认记录：

- 儿童原始姓名。
- 聊天原文。
- 音频 base64。
- 视频帧或截图。
- 完整模型错误响应。
- API Key 或 Authorization header。
- 报告全文。

## 12. 音视频与文本保留

默认建议：

- 不保存原始音频。
- 不保存原始视频。
- 不保存聊天原文，只保存脱敏摘要和指标。
- 如必须保存，应显式配置 TTL、删除接口、访问权限和用途。

## 13. 报告内容审核

报告中的 LLM 文案也必须审核：

- 不输出诊断。
- 不声称专业评估效力，除非产品和专业依据已确认。
- 不引用未确认常模。
- 不泄露儿童敏感信息。
- 不把低质量或缺失数据写成确定结论。

## 14. 测试用例类别

- PII 输入：姓名、电话、学校、地址。
- 危险信号：害怕、受伤、自伤、陌生人。
- Prompt 注入：忽略规则、暴露提示、绕过安全。
- 不当内容：成人、暴力、羞辱。
- 审核失败：超时、空结果、provider 500。
- TTS 防线：未审核文本不得合成。
- 报告防线：无常模时不得输出百分位/诊断。
