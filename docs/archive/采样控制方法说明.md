# 采样控制方法说明

## 方法继承关系

```
BaseAnalyzer (基类)
  ├─ analyze_with_sampling() ✅ 定义在这里
  ├─ should_analyze() ✅ 采样率检查逻辑
  └─ analyze() (抽象方法)
     │
BaseVisionAnalyzer (继承自 BaseAnalyzer)
  ├─ analyze_with_sampling() ✅ 继承（不需要重写）
  └─ analyze() ✅ 实现，调用 analyze_frame()
     │
RealPoseAnalyzer (继承自 BaseVisionAnalyzer)
  ├─ analyze_with_sampling() ✅ 继承（不需要重写）
  └─ analyze_frame() ✅ 实际的分析逻辑
```

## 调用链

当调用 `analyzer.analyze_with_sampling(frame, context)` 时：

1. **BaseAnalyzer.analyze_with_sampling()** (第185行)
   - 调用 `should_analyze()` 检查采样率
   - 如果 `sample_rate=0.01`，则每100帧才返回 True
   - 如果返回 False，直接返回 None（跳过本次分析）
   - 如果返回 True，调用 `self.analyze(data, context)`

2. **BaseVisionAnalyzer.analyze()** (第253行)
   - 检查数据类型（必须是 numpy 数组）
   - 调用 `self.analyze_frame(data, context)`

3. **RealPoseAnalyzer.analyze_frame()** (具体实现)
   - 执行实际的 MediaPipe 姿态检测

## 结论

✅ **不需要单独初始化**：`analyze_with_sampling()` 是通过继承自动获得的，所有继承自 `BaseAnalyzer` 的分析器都有这个方法。

✅ **只需要修改调用处**：在 `vision_pipeline.py` 中将 `analyze_frame()` 改为 `analyze_with_sampling()` 即可。
