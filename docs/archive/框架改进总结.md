## ✅ 已完成的改进

### 1. ✨ 分析器注册表（Registry）

**新增文件**: `app/core/registry.py`

**核心功能**:
- 统一管理所有分析器和比对器的注册
- 支持 Mock/Real 版本自动切换
- 提供便捷的创建和查询接口
- 支持装饰器语法糖

**主要类**:
```python
class AnalyzerRegistry:
    - register_analyzer()    # 注册分析器
    - register_matcher()     # 注册比对器
    - create_analyzer()      # 创建分析器实例
    - create_matcher()       # 创建比对器实例
    - list_analyzers()       # 列出所有分析器
    - get_analyzer_class()   # 获取分析器类
```

**使用示例**:
```python
# 注册
AnalyzerRegistry.register_analyzer('face', MockFaceAnalyzer, RealFaceAnalyzer)

# 创建
analyzer = AnalyzerRegistry.create_analyzer('face', mode=AnalyzerMode.REAL)
```

---

### 2. ⚙️ 配置管理器（Config Manager）

**新增文件**: `app/core/config_manager.py`

**核心功能**:
- 支持 YAML 配置文件
- 环境变量覆盖
- 分层配置（全局 + 单个分析器）
- 运行时配置切换

**主要类**:
```python
class AnalyzerConfigManager:
    - get_analyzer_mode()     # 获取分析器模式
    - get_analyzer_config()   # 获取分析器配置
    - set_global_mode()       # 设置全局模式
    - save_config()           # 保存配置到文件
```

**配置文件示例** (`config/analyzers.yaml`):
```yaml
global:
  mode: mock  # 全局模式

analyzers:
  pose:
    mode: real  # 覆盖全局设置
    enabled: true
    sample_rate: 1.0
    model_path: models/pose.task
```

---

### 3. 🎛️ 采样控制

**修改文件**: `app/core/base_analyzer.py`

**新增功能**:
- `sample_rate` 参数：控制分析频率
- `should_analyze()` 方法：自动采样判断
- `analyze_with_sampling()` 方法：带采样的分析

**使用示例**:
```python
# 配置文件中
analyzers:
  face:
    sample_rate: 0.5  # 每2帧分析1次

# 或代码中
analyzer = RealFaceAnalyzer(config={'sample_rate': 0.33})  # 每3帧分析1次
```

### 5. 🏗️ 重构流水线

**修改文件**: `app/core/pipelines/vision_pipeline.py`

**主要改进**:

- 使用配置管理器读取配置
- 移除冗余的 if/else 判断
- 代码量减少约 40%

**对比**:

**改进前**:
```python
if use_real:
    from app.core.vision.real_pose_analyzer import RealPoseAnalyzer
    self._pose_analyzer = RealPoseAnalyzer(...)
else:
    self._pose_analyzer = MockPoseAnalyzer(...)
```

**改进后**:
```python
pose_mode = config_mgr.get_analyzer_mode('pose')
self._pose_analyzer = AnalyzerRegistry.create_analyzer('pose', mode=pose_mode)
```

## 🚀 使用示例

### 接入新模型（表情分析）

**1. 创建分析器**:
```python
# app/core/vision/real_face_analyzer.py
class RealFaceAnalyzer(BaseVisionAnalyzer):
    def __init__(self, mode=AnalysisMode.REALTIME, config=None):
        super().__init__(AnalyzerType.FACE, mode, config)
    
    def analyze_frame(self, frame, context):
        # 模型推理
        return AnalysisResult(...)
```

**2. 注册**:
```python
# app/core/auto_register.py
from app.core.vision.real_face_analyzer import RealFaceAnalyzer

AnalyzerRegistry.register_analyzer(
    'face',
    mock_cls=MockFaceAnalyzer,
    real_cls=RealFaceAnalyzer,
    category='vision',
    description='表情分析'
)
```

**3. 配置**:
```yaml
# config/analyzers.yaml
analyzers:
  face:
    mode: real
    enabled: true
    sample_rate: 1.0
```

**完成！** 框架会自动：
- 在流水线中创建分析器
- 根据配置切换 Mock/Real
- 应用采样控制
