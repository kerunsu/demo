# 阶段6：姿态分析模型接入规划

## 1. 背景与目标

### 1.1 当前状态

在前端（child.js）中已有经过验证的姿态匹配代码：
- `pose_estimator.js` - 使用 MediaPipe PoseLandmarker 进行姿态检测
- `pose_similarity.js` - 姿态归一化与相似度计算

后端已有完善的分析框架：
- Mock 姿态分析器 (`app/core/vision/pose_analyzer.py`)
- Mock 姿态比对器 (`app/core/matchers/pose_matcher.py`)
- 视觉流水线 (`app/core/pipelines/vision_pipeline.py`)
- 完整的数据流：视频帧 → 分析 → 比对 → 结果反馈

### 1.2 核心目标

**将前端已验证的姿态检测逻辑迁移到后端，实现真正的姿态分析与比对功能。**

具体包括：
1. 后端实现真实的姿态关键点检测
2. 后端实现姿态归一化与相似度计算
3. 在播放课程时自动设置目标姿态
4. 实时返回匹配分数给前端显示

### 1.3 业务场景

```
模仿课程流程：
1. 教师选择"模仿"课程，点击播放
2. 儿童端显示目标姿态图片（如：举手、叉腰等）
3. 后端从目标图片提取姿态关键点作为比对目标
4. 儿童模仿姿态，摄像头捕获视频帧
5. 后端实时分析视频帧，计算与目标的相似度
6. 教师端实时显示匹配分数
7. 匹配成功（分数 > 阈值）时触发表扬
```

### 4.2 姿态归一化（移植自 pose_similarity.js）

```python
import numpy as np

def normalize_pose(landmarks: List[Dict]) -> List[List[float]]:
    """
    姿态归一化：平移到髋部中心，缩放到躯干长度
    
    Args:
        landmarks: 33个关键点，每个包含 x, y, z, visibility
    
    Returns:
        归一化后的坐标列表 [[x, y], ...]
    """
    # 取左右髋 (23, 24) 和左右肩 (11, 12) 的中点
    hip = np.array([
        (landmarks[23]['x'] + landmarks[24]['x']) / 2,
        (landmarks[23]['y'] + landmarks[24]['y']) / 2
    ])
    shoulder = np.array([
        (landmarks[11]['x'] + landmarks[12]['x']) / 2,
        (landmarks[11]['y'] + landmarks[12]['y']) / 2
    ])
    
    # 躯干长度作为尺度
    torso = np.linalg.norm(hip - shoulder)
    if torso < 1e-6:
        torso = 1e-6
    
    # 归一化
    normalized = []
    for lm in landmarks:
        normalized.append([
            (lm['x'] - hip[0]) / torso,
            (lm['y'] - hip[1]) / torso
        ])
    
    return normalized
```

### 4.3 相似度计算（移植自 pose_similarity.js）

```python
def pose_similarity(norm_a: List[List[float]], norm_b: List[List[float]]) -> float:
    """
    计算两个归一化姿态的相似度
    
    使用欧氏距离 + 高斯映射
    """
    n = min(len(norm_a), len(norm_b))
    
    # 计算平均点距
    total_dist = 0
    for i in range(n):
        dx = norm_a[i][0] - norm_b[i][0]
        dy = norm_a[i][1] - norm_b[i][1]
        total_dist += np.sqrt(dx*dx + dy*dy)
    
    avg_dist = total_dist / n
    
    # 高斯映射到 [0, 1]
    sigma = 0.6  # 可调参数
    similarity = np.exp(-(avg_dist ** 2) / (2 * sigma ** 2))
    
    return similarity
```

## 5. 风险与应对

### 5.1 模型加载性能

**风险：** MediaPipe 模型首次加载可能较慢

**应对：**
- 在应用启动时预加载模型
- 使用 lite 版本模型
- 添加加载状态提示

### 5.2 推理延迟

**风险：** 实时姿态检测可能影响帧率

**应对：**
- 控制检测频率（如每5帧检测一次）
- 使用异步处理
- 监控延迟，必要时降级到 Mock

### 5.3 检测失败

**风险：** 某些帧可能检测不到姿态

**应对：**
- 保持上一次有效结果
- 检测失败时返回空结果，不影响流程
- 添加检测成功率统计
