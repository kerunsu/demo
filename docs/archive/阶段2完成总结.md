## 🔧 使用方法

### 视频录制

```python
from app.recorder import VideoRecorder
from app.config import Config
from app.session import get_session_manager
import numpy as np

# 创建会话
manager = get_session_manager()
session = manager.create_session(student_id=1, course_id=1)

# 创建录制器
video_path = Config.get_video_file_path(session.session_id)
recorder = VideoRecorder(video_path, session.session_id)

# 开始录制
recorder.start()

# 写入帧
frame = np.random.randint(0, 255, (720, 1280, 3), dtype=np.uint8)
recorder.write(frame)

# 停止录制
recorder.stop()
recorder.cleanup()
```

### 音频录制

```python
from app.recorder import AudioRecorder
from app.config import Config

# 创建录制器
audio_path = Config.get_audio_file_path(session_id)
recorder = AudioRecorder(audio_path, session_id)

# 开始录制（自动捕获麦克风）
recorder.start()

# 等待一段时间...

time.sleep(5.0)

# 停止录制
recorder.stop()
recorder.cleanup()
```

### 统一媒体录制

```python

# 写入音频块（如果启用了音频录制）
```

## 🎯 设计特点

1. **模块化设计**：基类定义统一接口，子类实现具体功能

3. **资源管理**：完善的资源清理机制，避免资源泄漏
4. **错误处理**：详细的异常处理和日志记录

6. **上下文管理**：支持with语句，自动管理资源

## ⚠️ 注意事项

1. **音频录制**：
   - 需要系统有可用的音频输入设备（麦克风）
   - pyaudio在某些系统上可能需要额外配置
   - 如果没有麦克风，音频录制会失败（这是正常的）

2. **视频录制**：
   - 需要确保有足够的磁盘空间
   - 视频文件大小取决于分辨率、帧率和录制时长
   - 编解码器选择会影响文件大小和质量

3. **性能考虑**：
   - 视频录制是同步操作，写入帧会阻塞
   - 音频录制使用后台线程，不会阻塞主线程
   - 建议使用队列缓冲视频帧，避免阻塞
