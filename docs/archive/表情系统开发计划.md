### 课程触发表情流程
```
Teacher 界面
  └─ play_resource(course_id, item_id)
      └─ robot_service.trigger_course_event()
          ├─ mapping_resolver.find_motions() → 获取动作列表
          ├─ mapping_resolver.find_emotion() → 获取表情 ← NEW
          ├─ motion_player.play(motions)

### 自动随机表情流程
```
Emotion 界面

## 向下兼容性保证

### 旧数据自动转换
```python
# mapping_resolver.py
def _normalize_action_data(self, data):
    """将旧格式转为新格式"""
    if isinstance(data, list):
        # 旧格式：["动作1", "动作2"]
        return {"motions": data, "emotion": "001_Eye.gif"}
    elif isinstance(data, dict):
        # 新格式：{"motions": [...], "emotion": "..."}
        if "motions" not in data:
            data["motions"] = []
        if "emotion" not in data:
            data["emotion"] = "001_Eye.gif"
        return data
    else:
        return {"motions": [], "emotion": "001_Eye.gif"}
```

## 风险与注意事项

### 1. 数据兼容性
- ⚠️ 必须确保旧数据自动转换正确
- ⚠️ 保存时需要验证数据格式完整性

### 2. WebSocket 同步
- ⚠️ 表情切换和动作触发需要时序协调
- ⚠️ 多客户端连接时避免表情冲突

### 3. 性能优化
- ⚠️ GIF文件较大时可能影响加载速度
- ⚠️ 考虑添加预加载机制

### 4. 用户体验
- ⚠️ 表情切换需要平滑过渡（淡入淡出）
- ⚠️ 60秒定时器需要有视觉反馈（可选）
