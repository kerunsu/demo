## 🚀 接入步骤（4 步走）

### 第 1 步：创建分析器类

根据你的模型类型，在对应目录下创建新文件：

| 模型类型 | 创建位置 | 继承基类 | 需要实现的方法 |
|---------|---------|---------|--------------|
| 视觉分析（单帧） | `app/core/vision/` | `BaseVisionAnalyzer` | `analyze_frame(frame, context)` |
| 音频分析（实时） | `app/core/audio/` | `BaseAudioAnalyzer` | `analyze_chunk(chunk, context)` |
| 滑动窗口分析 | `app/core/vision/` 或 `audio/` | `BaseWindowAnalyzer` | `analyze_window(video_frames, audio_chunks, context)` |
| 比对器 | `app/core/matchers/` | `BasePoseMatcher` 或 `BaseSpeechMatcher` | `set_target()`, `extract_features()`, `compute_similarity()` |

```python
)

    """
    真实表情分析器

    """

        self,
        mode: AnalysisMode = AnalysisMode.REALTIME,
        config: Optional[Dict[str, Any]] = None
    ):
        # 必须调用父类构造函数，指定分析器类型
        super().__init__(AnalyzerType.FACE, mode, config)
        
        self._config = config or {}
        self._model = None  # 你的模型实例
        
        logger.info("真实表情分析器已创建")
    
    def initialize(self) -> bool:
        """
        初始化模型（只会被调用一次）
        
        在这里加载模型权重，避免每帧都加载
        """
        if self._is_initialized:
            return True
        
        try:
            # ========== 在这里加载你的模型 ==========
            # 例如：
            # import your_model_lib
            # self._model = your_model_lib.load_model("path/to/model")
            # =========================================
            
            self._is_initialized = True
            logger.info("真实表情分析器初始化成功")
            return True
            
        except Exception as e:
            logger.error(f"初始化失败: {e}")
            return False
    
    def analyze_frame(
        self,
        frame: np.ndarray,
        context: AnalysisContext
    ) -> Optional[AnalysisResult]:
        """
        分析单帧视频
        
        Args:
            frame: 视频帧（BGR 格式 numpy 数组，shape: [H, W, 3]）
            context: 分析上下文（包含 session_id, frame_index 等）
        
        Returns:
            分析结果，如果分析失败返回 None
        """
        # 确保已初始化
        if not self.is_ready:
            if not self.initialize():
                return None
        
        try:
            # ========== 在这里执行你的模型推理 ==========
            # 例如：
            # import cv2
            # frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            # result = self._model.predict(frame_rgb)
            # 
            # emotion = result['emotion']      # "happy", "sad", "neutral" 等
            # confidence = result['confidence'] # 0.0 ~ 1.0
            # box = result['face_box']          # [x, y, w, h]
            # =============================================
            
            # 模拟数据（替换为你的真实结果）
            emotion = "happy"
            confidence = 0.95
            box = [100, 100, 200, 200]
            
            # 构建分析结果数据
            data = {
                'emotion': emotion,
                'face_box': box,
                # 可以添加更多字段...
            }
            
            # 返回标准格式的结果
            return AnalysisResult(
                session_id=context.session_id,
                analyzer_type=self._analyzer_type.value,  # "face"
                mode=self._mode,
                timestamp=time.time(),
                data=data,
                confidence=confidence,
                frame_index=context.frame_index
            )
            
        except Exception as e:
            logger.error(f"分析失败: {e}")
            return None
    
    def cleanup(self) -> None:
        """清理模型资源（可选）"""
        if self._model:
            # 释放模型资源
            self._model = None
        self._is_initialized = False
        logger.info("资源已清理")
```

## 📦 输入输出规范

### 输入数据格式

| 类型 | 格式 | 说明 |
|-----|------|-----|
| 视频帧 | `np.ndarray` (H, W, 3) | BGR 格式，OpenCV 默认格式 |
| 音频块 | `bytes` | PCM 音频数据 |
| 上下文 | `AnalysisContext` | 包含 session_id, frame_index 等 |

### 输出数据格式

所有分析器必须返回 `AnalysisResult` 对象：

```python
AnalysisResult(
    session_id="xxx",           # 会话ID（从 context 获取）
    analyzer_type="face",       # 分析器类型标识符
    mode=AnalysisMode.REALTIME, # 分析模式
    timestamp=1703232000.0,     # Unix 时间戳
    data={                      # 核心分析数据（自定义）
        'emotion': 'happy',
        'confidence': 0.95,
        # ...
    },
    confidence=0.95,            # 整体置信度 0.0 ~ 1.0
    frame_index=100             # 帧索引（视觉）或 audio_chunk_index（音频）
)
```

比对器返回 `MatchResult` 对象：

```python
MatchResult(
    session_id="xxx",
    matcher_type="speech_matcher",
    timestamp=1703232000.0,
    score=0.85,                 # 匹配分数 0.0 ~ 1.0
    passed=True,                # 是否达到阈值
    threshold=0.8,              # 使用的阈值
    details={...}               # 详细信息
)
```

## ❓ 常见问题

### Q: 模型文件放在哪里？

A: 推荐放在项目根目录的 `models/` 文件夹下，并在分析器中使用相对路径。

### Q: 需要安装新的依赖包？

A: 请更新 `requirements.txt` 文件，添加你需要的依赖。

### Q: 模型推理太慢怎么办？

A: 几个建议：
1. 在 `initialize()` 中加载模型到 GPU
2. 在流水线中设置跳帧逻辑（如每 3 帧分析一次）
3. 使用模型量化/剪枝

### Q: 分析器抛出异常会怎样？

A: 框架会捕获异常并记录日志，不会影响其他分析器运行。但建议在 `analyze_frame()` 内部做好异常处理，返回 `None` 而不是抛出异常。
