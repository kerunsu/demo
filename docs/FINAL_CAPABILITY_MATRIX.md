## Acceptance Summary

| Category | 当前事实 |
| --- | --- |
| Defined interfaces | STT, TTS, LLM, Safety, Attention, Language, media, behavior frames, assessments, reports, WebSocket events, and persistence repositories are defined. |
| Implemented providers | Mock STT/TTS/LLM/Safety/Attention/Language remain available. Local Vosk, local Piper, local attention descriptor provider, rule chat/safety, deterministic assessment, expanded report, and SQLite persistence are implemented. |
| Main-flow integration | MediaRecorder -> backend media ingress -> Vosk, Safety/Rule -> Piper -> `/robot` ACK, camera descriptor -> local attention -> aggregation -> assessment/report -> SQLite are connected in the product path. |
| Default enabled for development | `.env.example` enables local STT/TTS/attention and SQLite. Runtime fallback and production template stay conservative. |
| Current dev-machine validation | Automated backend/frontend/E2E, Python voice, and SQLite integration tests passed with synthetic/non-child fixtures. |
| Dual-host pending | Live microphone/camera permissions, robot speaker/display, LAN CORS/firewall/WebSocket reconnect, lighting/noise, and long-run operations require field acceptance. |
| Explicit non-claims | No precise gaze point, clinical attention, professional score, percentile, diagnosis, or cloud LLM acceptance is claimed. |
