### 阶段2：后端API优化 ✅
**文件**: `app.py`

修改了 `/api/getSequencingImages` 接口：

**主要变更**:
- 支持类别映射：`size`→`BigSmall`, `length`→`LongShort`, `height`→`TallShort`, `count`→`MoreLess`
- 按物品前缀分组返回图片
- 每张图片包含`path`和`level`字段
- `level`从文件名数字后缀提取，表示大小关系

**返回格式示例**:
```json
{

    "Circle": [
      {"path": "/static/resources/images/paixu/BigSmall/Circle1.png", "level": 1},
      {"path": "/static/resources/images/paixu/BigSmall/Circle2.png", "level": 2},
      {"path": "/static/resources/images/paixu/BigSmall/Circle3.png", "level": 3},
      {"path": "/static/resources/images/paixu/BigSmall/Circle4.png", "level": 4}
    ],
    "Square": [...]
  },
  "category": "size"
}
```

### 阶段3：后端Socket事件处理 ✅
**文件**: `app/sockets/events.py`

新增了6个排序游戏专用Socket事件：

| 事件名 | 方向 | 功能 |
|--------|------|------|
| `sequencing_set_config` | 教师→儿童 | 设置游戏配置（自动模式、类别、规则） |
| `sequencing_start` | 教师→儿童 | 启动游戏 |
| `sequencing_next` | 教师→儿童 | 强制进入下一题 |
| `sequencing_hint` | 教师→儿童 | 显示提示效果 |
| `sequencing_status_update` | 儿童→教师 | 状态更新（题号、正确率、类别统计） |
| `sequencing_game_end` | 儿童→教师 | 游戏结束通知 |

**特点**:
- 使用sessionId作为Socket.IO房间进行房间广播
- 完整的日志记录
- 与配对课程事件结构一致

**文件**: `templates/sequencing.html`（已完全重写）

**主要特性**:

- **手动模式**:

- 与配对课程完全一致的视觉效果

#### 5. 反馈动画
- 正确：绿色背景+放大+发光
- 错误：灰度滤镜+缩小+半透明

## 📝 注意事项

1. **排序课程entry_file路径**: `resources/interactive/sequencing.html`
   - 注意是在`templates`目录而非`static`目录
   - Flask会正确渲染模板

2. **图片资源路径**: `/static/resources/images/paixu/{类别}/`
   - BigSmall, LongShort, TallShort, MoreLess

3. **类别映射**: 前端使用`size/length/height/count`，后端API自动映射到文件夹名

4. **难度锁定**: 当前仅支持"两者"比较，三者/四者排序后续扩展

5. **配置生效时机**: 教师切换滑块后，点击"下一个"时才生效（避免打断当前题）

6. **自动模式优先**: 默认开启，开启时滑块不可交互但显示同步
