# 课程资源导入开发规划

## 📋 需求分析

### 现状
| 方面 | 当前实现 | 新需求 |
|------|----------|--------|
| **命名课程** | 每个item对应单个图片文件 `file: "cat_1.png"` | 每个item对应**文件夹**，播放时**随机选择**一张图片 |
| **模仿课程** | 每个item对应单个文件（图片/视频） | 同命名课程 + 支持视频类型 |
| **拟声课程** | 每个item对应单个文件 | 同命名课程，资源在 `voice/` 文件夹 |

### 资源结构
```
static/resources/images/
├── naming/
│   ├── 001/  (猫 - 9张图片)
│   │   ├── 001.png
│   │   ├── 002.png
│   │   └── ...
│   ├── 002/  (狗)
│   └── ... (共56个文件夹)
└── voice/
    ├── 201/  (5张图片)
    ├── 202/
    └── ... (共7个文件夹)
```

### 核心问题
1. **文件夹到名称的映射**：文件夹名是 `001`，但需要知道它代表"猫"
2. **随机播放逻辑**：需要在服务端或客户端实现文件夹内随机选择
3. **数据库设计**：当前 `media_file` 字段存储单个文件路径，需要支持文件夹路径

## 🎯 设计方案

### 方案A：服务端随机选择（推荐 ✅）

**原理**：教师端点击item时，服务端从文件夹随机选择一个文件，将完整路径发给儿童端。

**数据流**：
```
教师点击"猫" → play_resource(itemId=1)
              → 服务端查询 CourseItem.media_file = "resources/images/naming/001/"
              → 服务端随机选择 "resources/images/naming/001/003.jpg"
              → 发送给儿童端 {file: "resources/images/naming/001/003.jpg"}
              → 儿童端直接播放
```

**优点**：
- 儿童端代码**几乎无需改动**
- 随机逻辑集中在服务端，易于维护
- 姿态分析可以拿到实际的图片路径

**改动点**：
1. `PlayResourceHandler.handle()` - 增加随机选择逻辑
2. 数据库 - `media_file` 字段存储文件夹路径
3. 新增工具函数 - 获取文件夹内随机文件

### 方案B：前端随机选择

**原理**：服务端发送文件夹路径，儿童端请求文件列表后随机选择。

**缺点**：
- 增加一次HTTP请求
- 需要暴露文件列表API
- 姿态分析时服务端不知道实际播放的是哪张图片

**不推荐**。

### 阶段2：服务端随机选择逻辑

#### 2.1 新增工具函数 `app/utils/resource_utils.py`
```python
import os
import random
from pathlib import Path
from app.config import Config

def get_random_file_from_folder(folder_path: str, extensions=('.png', '.jpg', '.jpeg', '.gif')) -> str | None:
    """
    从文件夹中随机选择一个文件
    
    Args:
        folder_path: 相对于 static 的文件夹路径，如 "resources/images/naming/001/"
        extensions: 允许的文件扩展名
    
    Returns:
        随机文件的完整相对路径，如 "resources/images/naming/001/003.jpg"
        如果文件夹不存在或为空，返回 None
    """
    full_path = Config.STATIC_DIR / folder_path
    if not full_path.exists() or not full_path.is_dir():
        return None
    
    files = [f for f in full_path.iterdir() 
             if f.is_file() and f.suffix.lower() in extensions]
    
    if not files:
        return None
    
    selected = random.choice(files)
    return f"{folder_path.rstrip('/')}/{selected.name}"

def is_folder_path(path: str) -> bool:
    """判断路径是否为文件夹路径（以 / 结尾）"""
    return path.endswith('/')
```

#### 2.2 修改 `app/sockets/handlers.py` - PlayResourceHandler
在转发 `play_resource` 事件前，处理文件夹随机选择：

```python
# 在 handle() 方法中，创建会话后，转发事件前：

# 查询课程项详情
if course_id and item_id:
    from database.models import CourseItem
    course_item = CourseItem.query.get(item_id)
    if course_item and course_item.media_file:
        from app.utils.resource_utils import is_folder_path, get_random_file_from_folder
        
        media_path = course_item.media_file
        if is_folder_path(media_path):
            # 文件夹路径，随机选择一个文件
            random_file = get_random_file_from_folder(media_path)
            if random_file:
                # 将实际文件路径放入转发数据
                data['resolvedFile'] = random_file
                logger.info("随机选择资源: %s -> %s", media_path, random_file)
```
