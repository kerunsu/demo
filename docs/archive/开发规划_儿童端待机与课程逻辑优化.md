# 开发规划：儿童端待机与课程逻辑优化

> 目标：围绕儿童端待机显示、初次进入提问语音、末项表扬后不再提问、配对/排序自动启动四类问题进行修复与优化。

## 一、问题理解与目标
1. **待机图片切换**：只要教师端不在控制界面，儿童端必须显示待机图片。
2. **首次进入控制界面**：自动播放第一个课程内容时，需要同时触发“提问语音”。
3. **最后一项表扬结束**：表扬视频结束后不应再触发“提问语音”。
4. **配对/排序课程停留等待**：教师端无“启动游戏”按钮，配对/排序需自动启动，避免“等待启动”界面卡住。

## 二、设计方案（高层）
### 1) 待机图片控制（教师端→儿童端信号）
- **新增 Socket 事件**：教师端离开控制界面时发送 `teacher_leave_control`，进入控制界面时发送 `teacher_enter_control`。
- **儿童端处理**：收到 `teacher_leave_control` 立即显示待机图片；收到 `teacher_enter_control` 隐藏待机图片。
- **退场覆盖**：在离开控制界面时，若正在播放课程或表扬视频，可显示过渡遮罩后显示待机图片，避免镜头闪回。

### 2) 首次进入控制界面自动提问语音
- **问题根因推测**：首播触发依赖 `play_resource` 的 `aux.question`，但自动播放逻辑或首次 `play_resource` 消息未触发语音播放路径。
- **修复策略**：
  - 教师端首次自动播放时强制带 `aux.question = true`（或在后端首次 `play_resource` 统一补充）。
  - 儿童端收到 `play_resource`，如果是新会话且 `aux.question`，确保走“内容加载完成后播放提问语音”的逻辑。

### 3) 最后一项表扬结束不再提问
- **修复策略**：
  - 教师端在收到 `praise_video_ended` 时，判断是否已到最后一个课程/子项；如果是最后一项，**不再**触发 `playCurrentItem({ question: true })`。
  - 仍然允许结束后触发“完成确认”或其他业务逻辑（保持现有行为）。

### 4) 配对/排序自动启动
- **问题根因推测**：儿童端等待 `matching_start` / `sequencing_start` 事件，但教师端没有对应按钮触发。
- **修复策略**（二选一，优先A）：
  - **A. 教师端自动启动**：在课程切换到配对/排序时，自动发送 `matching_start`/`sequencing_start`，或直接在 `play_resource` 回调里触发（当 `courseType` 为配对/排序且非 aux）。
  - **B. 儿童端自启动**：当配对/排序页面加载完成且收到 `sessionId` 时，自动调用 `startGame()`（需谨慎，避免与教师端重复触发）。

## 三、实施步骤（拟）
1. **Socket 事件新增与绑定**
   - 教师端：进入/离开控制界面时 emit 新事件。
   - 后端：转发事件到儿童端。
   - 儿童端：处理事件，显示/隐藏待机图。

2. **首次自动提问语音修复**
   - 检查教师端首次自动播放调用链，确保携带 `aux.question`。
   - 若已有标志，补充儿童端“内容就绪后播放”逻辑的兜底。

3. **末项表扬结束不再提问**
   - 在教师端 `praise_video_ended` 回调中增加“是否最后一项”判断。
   - 最后一项：仅触发结束/完成逻辑，不再自动提问。

4. **配对/排序自动启动**
   - 选择方案A或B（建议A）。
   - 实现自动发送 `matching_start`/`sequencing_start`。
   - 验证游戏在进入课程时自动开始，且不与现有流程冲突。

## 四、影响文件（预估）
- 教师端：teacher_frontend/components/ControlPage.tsx
- 儿童端：static/js/child.js
- 后端：app/sockets/events.py（新增事件转发）
- 儿童端页面（如需）：templates/child.html、static/css/child.css
- 交互课页面（如采用B方案）：static/resources/interactive/matching.html、sequencing.html

## 五、验收标准
1. 教师端离开控制界面后，儿童端立即显示待机图；回到控制界面后恢复课程内容显示。
2. 首次进入控制界面，儿童端显示内容并播放提问语音。
3. 最后一项表扬结束后不播放提问语音。
4. 配对/排序课程进入后自动开始，不停留“等待启动”。

## 六、风险与兜底
- **事件顺序**：控制界面切换与课程播放事件冲突时，优先展示待机图。
- **重复启动**：配对/排序自动启动需避免重复触发（通过一次性标记或判定游戏状态）。
