# 教师端"提示"按钮开发规划

## 1. 需求分析

### 1.1 目标
在教师端控制界面 (`ControlPage.tsx`) 新增"提示"按钮，形成田字格 2×2 布局：

```
┌───────────┬───────────┐
│   提问    │   提示    │
├───────────┼───────────┤
│   表扬    │  下一个   │
└───────────┴───────────┘
```

### 1.2 现有按钮功能分析

以"提问"按钮为参考，完整的按钮功能链路如下：

```
[教师端 ControlPage.tsx]
    └── 点击"提问"按钮
        └── playCurrentItem({ question: true })
            └── socket.emit('play_resource', { 
                    action: 'play',
                    studentId, courseId, itemId, courseType,
                    aux: { question: true, targetImage, targetText }
                })
                    │
                    ▼
[后端 handlers.py - PlayResourceHandler]
    └── 检测到是 aux 操作（question/praise/hint）
        └── 调用 AudioService.process_play_resource()
            │
            ▼
[后端 service.py - AudioService]
    └── 检查 aux.question === true
        └── 调用 AudioEmitter.emit_for_course(room, courseType, 'question')
            │
            ▼
[后端 events.py - AudioEventEmitter]
    └── 从 audio_manifest.yaml 查找课程对应的语音条目
        └── 例如 naming 课程 → attention_whats_this
            └── 随机选择一个音频文件
                └── socketio.emit('play_audio', { entry_id, file_path }, room)
                    │
                    ▼
[儿童端 child.html / audio_player.js]
    └── 接收 'play_audio' 事件
        └── 播放对应的音频文件
```

### 1.3 "提示"按钮需要的功能

"提示"按钮应该：
1. **触发语音播放**：播放提示类语音（如"看我"、"注意"等）
2. **引导儿童注意力**：当儿童注意力不集中时使用
3. **⭐ 游戏课程专用提示**：
   - **排序课程**：发送 `sequencing_hint` 事件，触发正确答案高亮提示
   - **配对课程**：发送 `matching_hint` 事件，触发正确答案高亮提示

### 3.2 详细修改计划

#### A. 修改"提示"按钮逻辑 (`ControlPage.tsx`)

**当前实现**（统一调用 playCurrentItem）：
```tsx
<button onClick={() => playCurrentItem({ hint: true })}>提示</button>
```

**目标实现**（根据课程类型区分处理）：
```tsx
// 新增提示处理函数
const handleHint = useCallback(() => {
  const courseType = currentCourse?.type;
  
  if (courseType === 'ordering' && sequencingGameStarted) {
    // 排序课程：发送专用提示事件
    handleSequencingHint();
  } else if (courseType === 'pairing' && matchingGameStarted) {
    // 配对课程：发送专用提示事件
    handleMatchingHint();
  } else {
    // 其他课程：播放提示语音
    playCurrentItem({ hint: true });
  }
}, [currentCourse, sequencingGameStarted, matchingGameStarted, ...]);

// 提示按钮
<button onClick={handleHint}>提示</button>
```

#### B. 新增配对课程提示函数 (`ControlPage.tsx`)

```tsx
// 配对游戏：发送提示
const handleMatchingHint = useCallback(() => {
  if (socketRef.current?.connected) {
    socketRef.current.emit('matching_hint', {
      sessionId: currentSessionId
    });
    console.log('💡 发送配对游戏提示');
```

#### C. 后端添加 `matching_hint` 事件处理 (`events.py`)

```python
@socketio.on('matching_hint')
def handle_matching_hint(data):
    """
    教师触发配对游戏提示 -> 转发给儿童端
    
    事件数据格式：
    {
        sessionId: str
    }
    """
    session_id = data.get('sessionId')
    logger.info("配对游戏提示: session=%s", session_id)
    
    if session_id:
        emit('matching_hint', data, room=session_id)
    else:
        emit('matching_hint', data, broadcast=True)
```
