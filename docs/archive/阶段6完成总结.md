### 6.2 实现真实姿态分析器 RealPoseAnalyzer

**文件**: `app/core/vision/real_pose_analyzer.py`

**功能**:
- 使用 MediaPipe PoseLandmarker 检测 33 个人体关键点
- 支持从图片检测姿态（用于设置目标）
- 支持从视频帧实时分析姿态
- 自动下载缺失的模型文件

**关键点定义** (MediaPipe 33点):
```
0: nose, 1-6: eyes, 7-8: ears, 9-10: mouth
11-12: shoulders, 13-14: elbows, 15-16: wrists
17-22: hands (pinky, index, thumb)
23-24: hips, 25-26: knees, 27-28: ankles
29-32: feet (heel, foot_index)
```

**输出数据结构**:
```python
{
    'keypoints': [...],           # 33个关键点
    'pose_type': 'standing',      # 姿态类型
    'pose_score': 0.85,           # 姿态评分
    'keypoint_count': 33,         # 关键点数量
    'visible_keypoints': 25,      # 可见关键点数
    'detection_time_ms': 20.5     # 检测耗时
}
```

### 6.3 实现真实姿态比对器 RealPoseMatcher

**文件**: `app/core/matchers/real_pose_matcher.py`

**功能**:
- 从图片/路径/关键点设置目标姿态
- 使用与前端 `pose_similarity.js` 一致的归一化和相似度算法
- 实时比对儿童姿态与目标姿态

**归一化算法** (移植自前端):
```python
# 以髋部中点为原点，躯干长度为尺度
hip = (keypoints[23] + keypoints[24]) / 2
shoulder = (keypoints[11] + keypoints[12]) / 2
torso = distance(hip, shoulder)
normalized = [(p - hip) / torso for p in keypoints]
```

**相似度算法**:
```python
# 高斯映射：距离越小，相似度越高
avg_dist = average([distance(a[i], b[i]) for i in range(n)])
similarity = exp(-(avg_dist²) / (2 * sigma²))  # sigma = 0.6
```

### 6.7 Bug修复：姿态匹配仅在模仿课程生效

**问题**: 切换到非模仿课程后，仍然显示姿态匹配分数

**原因**:
1. `default` 在允许设置姿态目标的列表中
2. `reset_session()` 未重置姿态目标

**修复**:

1. 移除 `default` 从允许列表:
```python
# handlers.py
if target_image and course_type in ['imitation', 'pose', 'mimic']:
    # 只有模仿类课程才设置姿态目标
```

2. `reset_session()` 调用 `reset_pose_target()`:
```python
# vision_pipeline.py
def reset_session(self) -> None:
    self._frame_count = 0
    self._analysis_results.clear()
    self._pose_matcher.reset_statistics()
    self.reset_pose_target()  # 新增：重置姿态目标
```

## 🔧 使用方式

### 1. 启用真实分析器

**方式一**: 环境变量（推荐）
```bash
# Windows
set USE_REAL_ANALYZERS=true
python app.py

# Linux/Mac
USE_REAL_ANALYZERS=true python app.py
```

**方式二**: 代码中调用
```python
from app.core.config import enable_real_analyzers
enable_real_analyzers()
```

**默认行为**: `app.py` 中默认为 `true`，启动时自动启用真实分析器。

### 2. 设置目标图片

前端在 `play_resource` 事件中传递：
```javascript
{
  action: "play",
  courseType: "mimic",  // 课程类型
  aux: {
    targetImage: "/resources/images/mimic/pose_1.png"  // 目标图片路径
  }
}
```

### 3. 接收匹配结果

前端监听 `match_result` 事件：
```typescript
socket.on('match_result', (data) => {
  console.log('匹配分数:', data.score);      // 0-1
  console.log('是否通过:', data.passed);     // boolean
  console.log('比对类型:', data.matcher_type); // 'pose_matcher'
});
```

## ⚠️ 注意事项

1. **模型文件**: 首次运行会自动下载 `pose_landmarker_lite.task`，需要网络连接
2. **课程类型**: 只有 `imitation`、`pose`、`mimic` 类型的课程才会进行姿态比对
3. **目标图片**: 确保课程项的 `file` 字段指向有效的图片路径
4. **性能考虑**: 真实分析器比 Mock 更消耗 CPU，低端设备可能需要降低帧率
