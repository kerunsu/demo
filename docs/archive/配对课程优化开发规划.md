# 配对课程优化开发规划

## 📋 需求分析

### 当前现状

| 组件 | 现状描述 |
|------|----------|
| **数据库** | Course 表无配对课程记录；CourseItem 无对应记录 |
| **教师端** | ControlPage.tsx 对 `pairing` 类型只是直接播放，无难度控制 |
| **儿童端 child.js** | 通过 iframe 加载 `matching.html`，传递 `courseId`, `courseType`, `itemId` 等 URL 参数 |
| **matching.html** | 独立运行，有自己的"开始游戏"按钮；内置难度递增逻辑（3选1→4选1→5选1）；图片从 `/api/getMatchingImages` 获取但当前实现只读取顶层文件，未遍历子文件夹 |
| **图片资源** | `static/resources/images/matching/` 下有 8 个子文件夹（057-064），每个子文件夹含同一物品的多张图片 |

### 目标需求

1. **数据库**：
   - Course 表添加配对课程（entry_file 指向 `resources/interactive/matching.html`）
   - CourseItem 表添加一条记录：`相同物品视觉配对`

2. **教师端控制界面**：
   - 针对配对课程，显示专用控制面板
   - 上方：4档难度滑块（二选一、三选一、四选一、五选一）
   - 下方：保留"提示"、"表扬"、"下一个"按钮

3. **儿童端 matching.html**：
   - 去掉"开始游戏"选择界面，由教师端控制启动
   - 接收教师端指定的难度参数
   - 保留自动递增难度逻辑（儿童端仍可自主进行）
   - 从子文件夹随机选图（同一轮内每个子文件夹只取一张作为一个"物品"）

4. **双向通信**：
   - 儿童端 → 教师端：当前难度、选择是否正确、正确率、是否结束
   - 教师端 → 儿童端：难度切换、开始游戏、下一题
   - 教师端：15题完成后自动触发"下一个"

### 新增 Socket.IO 事件

| 事件名 | 方向 | 数据结构 | 说明 |
|--------|------|----------|------|
| `matching_set_difficulty` | 教师→儿童 | `{difficulty: 2\|3\|4\|5}` | 设置难度等级（几选一） |
| `matching_start` | 教师→儿童 | `{sessionId}` | 启动游戏 |
| `matching_next` | 教师→儿童 | `{}` | 强制进入下一题 |
| `matching_hint` | 教师→儿童 | `{sessionId}` | 显示提示效果（正确选项高亮，错误选项变暗） |
| `matching_status_update` | 儿童→教师 | `{difficulty, questionIndex, isCorrect, accuracy, isFinished}` | 游戏状态更新 |
| `matching_game_end` | 儿童→教师 | `{accuracy, total, correct}` | 游戏结束 |

1. **修改 `/api/getMatchingImages`**：遍历子文件夹，每个子文件夹随机取一张图
```python
@app.route("/api/getMatchingImages")
def get_matching_images():
    """获取配对游戏图片列表 - 每个子文件夹随机取一张"""
    img_dir = Path(app.static_folder) / "resources" / "images" / "matching"
    images = []
    for subfolder in img_dir.iterdir():
        if subfolder.is_dir():
            files = [f for f in subfolder.iterdir() if f.suffix.lower() in ('.png', '.jpg', '.jpeg')]
            if files:
                selected = random.choice(files)
                images.append(f"/static/resources/images/matching/{subfolder.name}/{selected.name}")
    return jsonify({"images": images})
```

```javascript
  setDifficulty(level) {
    // level: 2, 3, 4, 5 对应几选一
    this.forcedDifficulty = level;

    debugLog(`难度设置为: ${level}选1`);
  }
  
  generateQuestion() {
    // 如果有强制难度，使用强制难度
    let numOptions = this.forcedDifficulty || this.getAutoDifficulty();
    // ... 其余逻辑
  }
  
  // 显示提示（标记正确答案）
  displayQuestion() {
    // ... 原有逻辑
    // 给正确答案卡片添加标记
    this.currentOptions.forEach((option, index) => {
      const card = document.createElement('div');
      if (option.id === this.currentTarget.id) {
        card.dataset.isCorrect = "true"; // 标记正确答案
      }
      // ... 其余逻辑
    });
  }
  
  // 提示功能实现
  showHint() {
    if (!this.isGameActive) return;
    
    const optionsGrid = document.getElementById('optionsGrid');
    const cards = Array.from(optionsGrid.children);
    
    cards.forEach(card => {
      // 跳过已选择的卡片
      if (card.classList.contains('wrong') || card.classList.contains('correct')) return;
      
      if (card.dataset.isCorrect === "true") {
        // 正确答案：黄色呼吸光晕
        card.classList.add('hint-highlight');
      } else {
        // 错误答案：变暗缩小
        card.classList.add('dimmed');
      }
    });
  }
}
```

## ⚠️ 注意事项

### 关键设计决策

1. **sessionId 传递**：通过 URL 参数传递给 iframe 内的 matching.html
2. **难度优先级**：教师端设置 > 儿童端自动递增
3. **自动进行保留**：即使教师不干预，儿童端仍可自动进行15题
4. **房间隔离**：使用 sessionId 作为 Socket.IO 房间，确保多学生同时上课时互不干扰

### 兼容性考虑

1. **iframe 与父页面通信**：matching.html 独立建立 Socket 连接，不依赖父页面
2. **URL 参数编码**：确保 sessionId 等参数正确编码
3. **旧版本兼容**：保留 matching.html 独立运行能力（无 sessionId 时使用本地逻辑）
