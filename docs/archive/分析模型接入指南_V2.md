# 🚀 分析模型接入指南 V2.0

> **全新升级**：基于注册表和配置管理器的模块化接入方式

本文档指导团队成员如何将**真实 AI 模型**接入到后端分析框架中。相比 V1.0，新版本大幅简化了接入流程，只需 **2-3 步**即可完成。

## 🎯 接入步骤（简化版）

### 第 1 步：创建分析器类

根据你的模型类型，在对应目录下创建新文件并继承对应基类：

| 模型类型 | 文件位置 | 继承基类 | 核心方法 |
|---------|---------|---------|---------|
| 视觉分析 | `app/core/vision/real_XXX_analyzer.py` | `BaseVisionAnalyzer` | `analyze_frame()` |
| 音频分析 | `app/core/audio/real_XXX_analyzer.py` | `BaseAudioAnalyzer` | `analyze_chunk()` |
| 比对器 | `app/core/matchers/real_XXX_matcher.py` | `BasePoseMatcher` 或 `BaseSpeechMatcher` | `set_target()` 等 |

### 📝 代码模板：视觉分析器

**文件**: `app/core/vision/real_face_analyzer.py`

```python
"""
真实表情分析器
使用 DeepFace/FER 模型进行表情识别
"""
import time
from typing import Optional, Dict, Any
import numpy as np

from app.core.base_analyzer import BaseVisionAnalyzer
from app.core.models import (
    AnalysisMode,
    AnalyzerType,
    AnalysisResult,
    AnalysisContext
)
from app.utils.logger import setup_logger

logger = setup_logger('real_face_analyzer')


class RealFaceAnalyzer(BaseVisionAnalyzer):
    """
    真实表情分析器
    """
    
    def __init__(
        self,
        mode: AnalysisMode = AnalysisMode.REALTIME,
        config: Optional[Dict[str, Any]] = None
    ):
        # 必须调用父类构造函数，指定分析器类型
        super().__init__(AnalyzerType.FACE, mode, config)
        
        self._config = config or {}
        self._model = None  # 你的模型实例
        
        logger.info("真实表情分析器已创建")
    
    def initialize(self) -> bool:
        """
        初始化模型（只会被调用一次）
        """
        if self._is_initialized:
            return True
        
        try:
            # ========== 在这里加载你的模型 ==========
            # 例如：
            # from deepface import DeepFace
            # self._model = DeepFace
            # =========================================
            
            self._is_initialized = True
            logger.info("真实表情分析器初始化成功")
            return True
            
        except Exception as e:
            logger.error(f"初始化失败: {e}")
            return False
    
    def analyze_frame(
        self,
        frame: np.ndarray,
        context: AnalysisContext
    ) -> Optional[AnalysisResult]:
        """
        分析单帧视频
        
        Args:
            frame: 视频帧（BGR 格式 numpy 数组，shape: [H, W, 3]）
            context: 分析上下文（包含 session_id, frame_index 等）
        
        Returns:
            分析结果，如果分析失败返回 None
        """
        # 确保已初始化
        if not self.is_ready:
            if not self.initialize():
                return None
        
        try:
            # ========== 在这里执行你的模型推理 ==========
            # result = self._model.analyze(frame)
            # =============================================
            
            # 模拟数据（替换为你的真实结果）
            emotion = "happy"
            confidence = 0.95
            
            # 构建分析结果数据
            data = {
                'emotion': emotion,
                'confidence': confidence,
            }
            
            # 返回标准格式的结果
            return AnalysisResult(
                session_id=context.session_id,
                analyzer_type=self._analyzer_type.value,
                mode=self._mode,
                timestamp=time.time(),
                data=data,
                confidence=confidence,
                frame_index=context.frame_index
            )
            
        except Exception as e:
            logger.error(f"分析失败: {e}")
            return None
    
    def cleanup(self) -> None:
        """清理模型资源（可选）"""
        if self._model:
            self._model = None
        self._is_initialized = False
        logger.info("资源已清理")
```

### 第 2 步：注册到自动注册模块

修改 `app/core/auto_register.py`，添加你的分析器：

```python
def register_all_analyzers():
    """注册所有分析器"""
    
    # ... 其他注册代码 ...
    
    # ========== 新增：表情分析器（Real 版本） ==========
    try:
        from app.core.vision.face_analyzer import MockFaceAnalyzer
        from app.core.vision.real_face_analyzer import RealFaceAnalyzer  # 导入你的类
        
        AnalyzerRegistry.register_analyzer(
            'face',
            mock_cls=MockFaceAnalyzer,
            real_cls=RealFaceAnalyzer,  # 注册 Real 版本
            category='vision',
            description='表情分析 (7种情绪)'
        )
    except ImportError as e:
        logger.warning(f"注册表情分析器失败: {e}")
    # ==================================================
```

**就这么简单！** 不需要修改流水线、不需要修改配置类。

### 比对器模板

**文件**: `app/core/matchers/real_speech_matcher.py`

```python
from app.core.base_matcher import BaseSpeechMatcher

class RealSpeechMatcher(BaseSpeechMatcher):
    """真实语音比对器"""
    
    def set_target_text(self, target_text: str) -> bool:
        """设置目标文本"""
        self._target = target_text.lower()
        self._target_features = target_text.lower()
        self._is_initialized = True
        return True
    
    def extract_features(self, data) -> Optional[str]:
        """提取特征（识别的文本）"""
        if hasattr(data, 'data'):
            return data.data.get('text', '').lower()
        return str(data).lower()
    
    def compute_similarity(self, features1: str, features2: str) -> float:
        """计算文本相似度"""
        if features1 == features2:
            return 1.0
        elif features2 in features1:
            return 0.8
        return 0.3
```

## ⚙️ 采样控制（新功能）

框架现在支持自动采样控制，避免每帧都分析：

```yaml
analyzers:
  face:
    sample_rate: 0.5  # 每2帧分析1次
```

或在代码中：

```python
analyzer = RealFaceAnalyzer(config={'sample_rate': 0.33})  # 每3帧分析1次
```

框架会自动调用 `should_analyze()` 来跳过不需要分析的帧。

## ❓ 常见问题

### Q: 如何临时切换到 Mock 模式调试？

A: 两种方式：
```bash
# 方式1：环境变量
USE_REAL_ANALYZERS=false python app.py

# 方式2：修改 config/analyzers.yaml
global:
  mode: mock
```

### Q: 如何只启用某些分析器的 Real 版本？

A: 在 `analyzers.yaml` 中单独指定：
```yaml
analyzers:
  pose:
    mode: real  # 姿态用 Real
  face:
    mode: mock  # 表情用 Mock
```

### Q: 采样率如何计算？

A: 
- `sample_rate = 1.0`：每帧都分析
- `sample_rate = 0.5`：每 2 帧分析 1 次
- `sample_rate = 0.33`：每 3 帧分析 1 次

### Q: 模型文件放在哪里？

A: 推荐放在项目根目录的 `models/` 文件夹，并在配置文件中指定路径。
