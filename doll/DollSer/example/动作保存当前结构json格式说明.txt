当前结构：
version：结构版本号（目前是 1，为了方便后续如果要调整结构的话旧版本也能接着用，没什么别的作用）
updatedAt：最后一次写入时间（UTC ISO 字符串）
motions：动作字典
	key：动作名（字符串）
	value：帧数组（按时间顺序）
		time：相对动作开始的毫秒时间戳
		pose：四个轴的角度值
			pitch
			yaw
			armL
			armR

示例：
{
  "version": 1,
  "updatedAt": "2026-04-30T08:59:52.175527+00:00",
  "motions": {

          "armR": 107.31
        }
      },
