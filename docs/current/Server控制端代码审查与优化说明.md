# Server 控制端代码审查与优化说明

> 2026-08-10 更新：实时监控的“三端连接与问题摘要”已改为解释型诊断。当前展示服务端、
> 教师端、儿童端、Robot Runtime 的在线状态、连接 IP、重复实例、影响和处理建议；
> 内部 commandId、控制模式和采样参数不再作为主界面表述。详见
> [三端协同稳定性根因与分阶段整改方案.md](三端协同稳定性根因与分阶段整改方案.md)。

## 1. 审查目标

Server 控制端必须区分“按钮已点击、服务端已接收、命令已入队、目标已接受、实际执行中、完整结束、降级结束和执行失败”。任何一层都不得用上一层的成功替代。

本次重点审查以下链路：

- 配置中心行为绑定的测试按钮；
- 动作、表情和行为调度器；
- Robot Runtime、Child Agent、机器人控制页和表情显示页的在线状态；
- 实时监控中的机器人运行状态和错误反馈；
- 控制端停止机器人输出、停止当前声音的操作。

## 2. 审查发现

### 2.1 测试按钮把“入队”显示成“成功”

旧测试接口在行为进入队列后立即返回成功，页面只显示“已加入试播队列”。动作目标离线、表情页未打开、动作文件不存在或后续执行失败，都无法反馈到原按钮。

### 2.2 监控台机器人状态是占位数据

旧 MonitorSnapshot 固定返回 `animation: null` 和 `audioPlaying: false`，没有读取 RobotService 的真实忙碌状态、当前行为或最后执行结果。因此控制端显示可能与后端实际运行完全不一致。

### 2.3 页面没有在线身份

`/robot` 和 `/robot/emotion` 虽然建立 Socket.IO 连接，但没有登记 `robot_control`、`robot_display` 身份。Server 无法判断动作控制页或表情显示页是否在线，也无法在试播前给出明确错误。

### 2.4 监控页控制按钮是永久禁用占位

旧“暂停”“静音”按钮带有 `disabled` 和“未接控制 API”，不能执行任何操作。

## 3. 优化后的执行真值模型

每次行为生成唯一 `commandId/behaviorId`，Server 冻结实际接受的计划并记录：

- 来源、控制模式、动作、表情；
- 计划时长、共同启动时间和延迟；
- `queued / running / completed / degraded / failed / cancelled` 生命周期；
- expression、motion、audio、childAnimation 各模态的 required/status/detail；
- 排队、开始、更新、结束时间；
- 错误、警告和执行目标。

控制端通过 `/api/robot/sequence/status/<commandId>` 查询同一份状态；实时监控通过 MonitorSnapshot 读取同一份最后命令，避免页面自行推测。

## 4. 目标在线与验证等级

| 控制通道 | 开始前检查 | 成功依据 | 明确限制 |
|---|---|---|---|
| Robot Runtime | Runtime 心跳在线 | Runtime HTTP 接受命令 | 代表 Runtime 接受，不等于机械结构物理传感器确认 |
| Child Agent | Agent 心跳在线 | Socket 命令成功下发 | 当前没有 Agent 动作完成回执，标记为下发级验证 |
| Server OSC | 本地通道可建立 | UDP 命令发出 | UDP 无接收/完成回执，必须显示 `unverified/degraded` |
| 机器人表情页 | `robot_display` 心跳在线 | 关联的 `robot_emotion_ended` | 表情页离线时试播直接拒绝，不允许伪报成功 |

## 5. 测试按钮行为

1. 使用页面当前尚未保存的绑定构造实际计划。
2. 检查动作执行目标与 `/robot/emotion` 是否在线。
3. 任一必需目标离线时拒绝执行并显示具体处理方式。
4. 接收成功后禁用当前按钮并持续轮询命令状态。
5. 页面显示后端实际选中的动作、表情、命令编号及每个模态状态。
6. 仅在终态到达后恢复按钮；超时会提示转到实时监控检查。
7. 配置页测试只验证机器人动作与表情，不播放课程语音，避免配置操作突然发声。完整课程语音与儿童端动画仍由教师端正式行为事务验证。

## 6. 运行控制与错误反馈

- “停止机器人输出”会取消当前行为、发送动作停止并恢复默认表情；命令状态标记为 `cancelled`。
- “停止当前声音”必须携带精确 sessionId，无法定位会话时明确拒绝，不做全局模糊广播。
- 实时监控显示控制模式、动作目标、表情页/控制页在线状态、最近 commandId、实际计划、生命周期和错误。
- 行为终态写入监控事件列表；失败显示红色，降级显示橙色。

## 7. 仍需现场验证的边界

- Server OSC 是 UDP 协议，没有硬件回执；代码只能确认命令发出，不能宣称舵机已经物理到位。
- Robot Runtime 当前确认到 HTTP 接受层；如需物理到位闭环，需要 Runtime 增加舵机/执行器完成回执。
- 本次环境没有可连接的浏览器实例，UI 通过静态契约、接口测试和生产构建验证；仍需在部署浏览器中点击一次全部测试按钮。
- 最终应在真实设备上分别验证 Robot Runtime、Child Agent 或 Server OSC 中实际启用的那一种模式。

## 8. 验收清单

- 表情页关闭时点击测试，页面明确提示打开 `/robot/emotion`，且不入队。
- Runtime/Agent 离线时包含动作的测试不入队，并显示目标离线。
- 测试执行过程中可看到 queued、running 和终态。
- 实际动作/表情与状态面板的 actual plan 一致。
- 表情播放结束回执只更新相同 commandId。
- UDP 模式不得显示“已确认完成”，只能显示未验证/降级。
- 停止机器人输出后，当前行为保持 cancelled，不被迟到计时改回 completed。
- 停止声音缺少 sessionId 时返回明确错误。
- 实时监控与测试按钮读取同一命令账本。
