## 📝 使用步骤

### 第1步：运行导入脚本（Dry-run 测试）

先进行 dry-run 测试，不会修改数据库：

```powershell
python database/import_course_resources.py
```

当提示时，输入 `d` 进行 dry-run。

**预期输出**：
```
✓ 读取到 63 条记录
✓ 验证通过 63 条记录
  - 命名课程项: 56 个
  - 拟声课程项: 7 个
```

### 第2步：正式导入数据

如果 dry-run 没有问题，重新运行：

```powershell
python database/import_course_resources.py
```

当提示时，输入 `y` 确认导入。

**导入内容**：
- 创建或更新"命名课程"和"拟声课程"
- 为每个课程创建对应的 CourseItem 记录
- `media_file` 字段存储文件夹路径（如 `resources/images/naming/001/`）
- `icon` 字段存储第一张图片作为缩略图
- `type` 字段设为 `image`

### 第3步：启动应用测试

```powershell
python app.py
```

访问 http://127.0.0.1:8080

### 第4步：测试课程播放

1. 打开教师端页面
2. 选择学生
3. 点击"命名课程"中的任意项（如"猫"）
4. 观察儿童端是否正确显示**随机选择**的图片
5. 多次点击同一项，应该看到不同的图片

### 数据库检查
```python
from database.models import db, Course, CourseItem
from app.config import Config

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = Config.SQLALCHEMY_DATABASE_URI

```

### 前端检查
1. 打开浏览器开发者工具（F12）→ Network 标签
2. 点击课程项
3. 查看 WebSocket 消息中是否包含 `resolvedFile` 字段
4. 儿童端应该加载该文件路径

### 日志检查
查看 `logs/app.log`，应该看到：
```
随机选择资源: resources/images/naming/001/ -> resources/images/naming/001/003.jpg
转发随机文件路径: resources/images/naming/001/003.jpg
```

## 🎯 工作原理

```
教师点击"猫" (itemId=1)
    ↓
服务端查询: CourseItem.media_file = "resources/images/naming/001/"
    ↓
检测到路径以 / 结尾（文件夹）
    ↓
从文件夹中随机选择: "resources/images/naming/001/003.jpg"
    ↓
WebSocket 转发: {resolvedFile: "resources/images/naming/001/003.jpg", ...}
    ↓
儿童端接收: imageEl.src = "/static/resources/images/naming/001/003.jpg"
    ↓
显示随机图片
```

## 🐛 常见问题

### Q1: 导入脚本报错"文件夹不存在"
**A**: 检查资源文件夹路径是否正确：
- 命名课程：`static/resources/images/naming/001/`
- 拟声课程：`static/resources/images/voice/201/`

### Q2: 儿童端不显示图片
**A**: 
1. 检查浏览器控制台是否有 404 错误
2. 确认 `resolvedFile` 字段已正确传递（查看 WebSocket 消息）
3. 确认图片文件路径正确

### Q3: 每次都显示同一张图片
**A**: 
1. 确认 `media_file` 字段以 `/` 结尾（表示文件夹）
2. 检查日志是否有"随机选择资源"的记录
3. 确认文件夹内有多个图片文件

### Q4: 数据库中已有测试数据怎么办？
**A**: 导入脚本会自动更新已有记录，不会重复创建。
