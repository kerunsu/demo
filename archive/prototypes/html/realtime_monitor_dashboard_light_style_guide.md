# 浅色医疗 / 教育管理系统视觉规范

## 定位

本版本保留原有深色控制中心版的全部信息架构、功能和交互，仅调整为更适合医疗机构、学校、康复中心和教育管理场景的浅色视觉体系。

## 视觉关键词

- 专业
- 清晰
- 可信
- 温和
- 医疗管理
- 教育数据
- 低刺激
- 高可读性

## 色彩系统

### 基础色

- 页面背景：`#F3F7FB`
- 主卡片：`#FFFFFF`
- 次级卡片：`#F8FBFE`
- 主文字：`#1E2D3D`
- 次级文字：`#6F8296`
- 分割线：`#DBE5EF`

### 状态色

- 主色 / 操作：`#3178C6`
- 正常：`#2D9D78`
- 运行中：`#2AA8C8`
- 警告：`#D69A25`
- 错误：`#D45B68`
- 降级或特殊 Provider：`#7B67C8`

## 页面结构

与深色版保持一致：

1. 顶部全局栏
2. 左上实时摄像头与注意力
3. 中上双屏状态预览
4. 右上语音与回答流水线
5. 中下三张实时图表
6. 右下课程实时指标
7. 右下事件时间线与告警
8. 底部服务健康状态

## 视觉差异

### 卡片

- 使用白色卡片
- 细描边
- 轻阴影
- 14px 圆角
- 标题栏使用非常浅的渐变或纯白

### 图表

- 使用低饱和蓝、青、紫、金色
- 网格线极浅
- 不使用黑色背景
- 图例和轴文字以蓝灰色呈现

### 摄像头区

- 画面边界使用浅蓝灰
- 人脸框仍使用绿色
- 画面模糊开关保留
- 不使用高对比霓虹效果

### 告警

- 普通提示使用浅蓝
- 警告使用浅黄
- 错误使用浅红
- 所有告警都同时使用文字标签，不能只依赖颜色

## 适用场景

浅色版更适合：

- 教师办公室
- 康复中心
- 医疗机构
- 课题汇报
- 白天演示
- 投影屏幕
- 长时间查看

## 与深色版的选择建议

- 深色版：适合控制中心、大屏演示、现场工程监控
- 浅色版：适合教学管理、医疗管理、课题汇报和日常使用

## Codex 实现建议

Codex 后续接入项目时，可将深色版与浅色版做成主题变量：

```ts
type MonitorTheme = "dark-control" | "light-clinical";
```

建议将颜色、阴影、边框和图表配色都抽成 CSS 变量，避免维护两套组件。

原有布局、数据接口和交互逻辑保持一致，仅切换主题 Token。
