# 排序课程优化开发规划

## 📋 需求分析

### 当前现状

| 组件 | 现状描述 |
|------|----------|
| **数据库** | Course 表无排序课程记录；CourseItem 无对应记录 |
| **教师端** | ControlPage.tsx 对排序类型无专用控制面板 |
| **儿童端 child.js** | 通过 iframe 加载 `sequencing.html`，传递 URL 参数 |
| **sequencing.html** | 独立运行，有自己的"开始游戏"选择界面；内置类别选择和难度递增逻辑 |
| **图片资源** | `static/resources/images/paixu/` 下有 4 个子文件夹（BigSmall、LongShort、MoreLess、TallShort），每个子文件夹内图片前缀相同的可比较，后缀数字越大表示越大/长/多/高 |

### 目标需求

1. **数据库**：
   - Course 表添加排序课程
   - CourseItem 表添加一条记录：`排序`

2. **教师端控制界面**：
   - 针对排序课程，显示专用控制面板
   - **第一行**：
     - "自动"开关按钮（默认开启）
     - 类别滑块：大小、长短、高矮、多少（4选1）
     - 难度滑块：两者、三者、四者（目前禁用，只能选"两者"）
     - 规则滑块：
       - 难度=两者时：显示"选大的/选小的"或"选长的/选短的"等（根据类别）
       - 难度≥三者时：显示"从小到大/从大到小"或"从短到长/从长到短"等（根据类别）
     - 开启自动时：所有滑块不可交互，显示内容与儿童端同步
   - **第二行**：每个类别的正确/错误数量统计
   - **下方**：保留"提示"、"表扬"、"下一个"按钮

3. **儿童端 sequencing.html**：
   - 去掉"开始游戏"选择界面，由教师端控制启动
   - 接收教师端指定的类别、难度、规则参数
   - 自动模式（默认）：每个类别出4题，规则随机切换，自动轮换类别
   - 手动模式：按教师端滑块设置出题
   - 界面简洁美化，与配对课程风格统一

4. **双向通信**：
   - 儿童端 → 教师端：当前类别、难度、规则、选择是否正确、各类别统计
   - 教师端 → 儿童端：自动/手动切换、类别/规则设置、开始游戏、下一题、提示

### 游戏逻辑说明

当前实际为"作比较"游戏（非真正排序）：
- 难度=两者：显示2张图片，儿童根据规则（选大的/选小的等）点击正确图片
- 图片选取：同一前缀的图片可比较，后缀数字决定大小关系

```python
@app.route("/api/getSequencingImages")
def get_sequencing_images():
    """获取排序游戏图片列表 - 按物品分组，包含大小关系"""
    category = request.args.get('category', 'BigSmall')
    
    # 类别映射
    category_map = {
        'size': 'BigSmall',
        'length': 'LongShort', 
        'height': 'TallShort',
        'count': 'MoreLess'
    }
    folder_name = category_map.get(category, category)
    
    img_dir = Path(app.static_folder) / "resources" / "images" / "paixu" / folder_name
    
    # 按前缀分组
    groups = {}
    for f in img_dir.iterdir():
        if f.suffix.lower() in ('.png', '.jpg', '.jpeg') and f.name != 'Background.png':
            # 提取前缀和数字: Circle1.png -> ('Circle', 1)
            import re
            match = re.match(r'(.+?)(\d+)\.', f.name)
            if match:
                prefix, num = match.group(1), int(match.group(2))
                if prefix not in groups:
                    groups[prefix] = []
                groups[prefix].append({
                    'path': f"/static/resources/images/paixu/{folder_name}/{f.name}",
                    'level': num  # 数字越大表示越大/长/多/高
                })
    
    # 对每组按 level 排序
    for prefix in groups:
        groups[prefix].sort(key=lambda x: x['level'])
    
    return jsonify({"groups": groups, "category": category})
```

#### 5.2 游戏类核心逻辑

```javascript
class SequencingGame {
  constructor() {
    this.sessionId = urlParams.get('sessionId');
    this.autoMode = true;
    this.category = 'size';
    this.difficulty = 2;
    this.rule = 'bigger';
    
    this.currentQuestion = 0;
    this.maxQuestions = 16;
    this.questionsPerCategory = 4;
    
    // 类别统计
    this.categoryStats = {
      size: { correct: 0, wrong: 0 },
      length: { correct: 0, wrong: 0 },
      height: { correct: 0, wrong: 0 },
      count: { correct: 0, wrong: 0 }
    };
    
    // 自动模式：类别队列
    this.categoryQueue = [];
    this.currentCategoryCount = 0;
  }
  
  setConfig(config) {
    if (config.autoMode !== undefined) this.autoMode = config.autoMode;
    if (!this.autoMode) {
      // 手动模式：使用教师设置
      if (config.category) this.category = config.category;
      if (config.rule) this.rule = config.rule;
    }
  }
  
  startGame() {
    this.currentQuestion = 0;
    this.resetStats();
    
    if (this.autoMode) {
      // 随机打乱类别顺序
      this.categoryQueue = this.shuffleArray(['size', 'length', 'height', 'count']);
      this.category = this.categoryQueue[0];
      this.currentCategoryCount = 0;
    }
    
    this.loadImages().then(() => {
      this.generateQuestion();
      this.hideOverlay();
    });
  }
  
  async loadImages() {
    const response = await fetch(`/api/getSequencingImages?category=${this.category}`);
    const data = await response.json();
    this.imageGroups = data.groups;
  }
  
  generateQuestion() {
    // 自动模式：每4题换类别，规则随机
    if (this.autoMode) {
      if (this.currentCategoryCount >= this.questionsPerCategory) {
        // 切换到下一个类别
        const nextIndex = this.categoryQueue.indexOf(this.category) + 1;
        if (nextIndex < this.categoryQueue.length) {
          this.category = this.categoryQueue[nextIndex];
          this.currentCategoryCount = 0;
          this.loadImages().then(() => this.generateQuestion());
          return;
        }
      }
      // 随机规则
      this.rule = this.getRandomRule();
    }
    
    // 随机选择一组图片
    const prefixes = Object.keys(this.imageGroups);
    const prefix = prefixes[Math.floor(Math.random() * prefixes.length)];
    const group = this.imageGroups[prefix];
    
    // 随机选2张不同的图片
    const shuffled = this.shuffleArray([...group]);
    this.options = shuffled.slice(0, 2);
    
    // 确定正确答案（根据规则）
    this.correctOption = this.getCorrectOption();
    
    this.displayQuestion();
  }
  
  getRandomRule() {
    const rules = {
      size: ['bigger', 'smaller'],
      length: ['longer', 'shorter'],
      height: ['taller', 'shorter'],
      count: ['more', 'less']
    };
    const options = rules[this.category];
    return options[Math.floor(Math.random() * options.length)];
  }
  
  getCorrectOption() {
    // 根据规则确定正确选项
    const isSelectBigger = ['bigger', 'longer', 'taller', 'more'].includes(this.rule);
    return this.options.reduce((a, b) => 
      isSelectBigger ? (a.level > b.level ? a : b) : (a.level < b.level ? a : b)
    );
  }
  
  selectOption(option) {
    const isCorrect = option.path === this.correctOption.path;
    
    // 更新统计
    this.categoryStats[this.category][isCorrect ? 'correct' : 'wrong']++;
    this.currentQuestion++;
    this.currentCategoryCount++;
    
    // 显示反馈动画
    this.showFeedback(option, isCorrect);
    
    // 上报状态
    socket.emit('sequencing_status_update', {
      sessionId: this.sessionId,
      category: this.category,
      rule: this.rule,
      isCorrect,
      questionIndex: this.currentQuestion,
      categoryStats: this.categoryStats
    });
    
    // 下一题或结束
    setTimeout(() => {
      if (this.currentQuestion >= this.maxQuestions) {
        this.finishGame();
      } else {
        this.generateQuestion();
      }
    }, 1000);
  }
  
  showHint() {
    // 与配对课程一致：正确选项高亮呼吸，错误选项变暗
    document.querySelectorAll('.option-card').forEach(card => {
      if (card.dataset.path === this.correctOption.path) {
        card.classList.add('hint-highlight');
      } else {
        card.classList.add('dimmed');
      }
    });
  }
  
  finishGame() {
    socket.emit('sequencing_game_end', {
      sessionId: this.sessionId,
      totalStats: this.categoryStats,
      totalQuestions: this.maxQuestions
    });
    this.showEndScreen();
  }
}
```

## ⚠️ 注意事项

### 关键设计决策

1. **难度暂时禁用**：只支持"两者比较"，三者/四者排序后续扩展
2. **配置生效时机**：教师切换滑块后，点击"下一个"时才生效
3. **自动模式优先**：开启自动时，滑块显示同步但不可交互
4. **房间隔离**：使用 sessionId 作为 Socket.IO 房间

### 与配对课程的差异

| 对比项 | 配对课程 | 排序课程 |
|--------|----------|----------|
| 控制面板 | 难度滑块（2-5选1） | 类别滑块 + 规则滑块 + 自动开关 |
| 游戏逻辑 | 找相同 | 比大小（两者比较） |
| 统计维度 | 总正确率 | 按类别统计 |
| 自动模式 | 无 | 有（默认开启） |

### 兼容性考虑

1. **旧版本兼容**：保留 sequencing.html 独立运行能力（无 sessionId 时使用本地逻辑）
2. **图片命名**：严格遵循 `{物品名}{数字}.png` 格式
