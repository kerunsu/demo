# 项目文件结构说明

## 项目概述
这是一个**教育训练系统**，用于教师管理学生、选择课程、进行训练评估。系统包含教师端、儿童端和服务器端，支持实时通信和训练数据记录。

## 二、核心模块说明

### 1. 后端模块（Flask）

#### `app.py` - 主应用文件
- **功能**：Flask应用入口，定义所有路由和API接口
- **主要功能模块**：
  - 页面路由：`/`, `/therapist`, `/child`, `/server`；`/sequencing`、`/matching` 重定向到 `static/resources/interactive/` 下静态页（保留 query）
  - 静态文件路由：CSS、JS、资源文件
  - PWA：当前已移除相关 manifest/service worker，按普通网页运行
  - **API接口**：
    - 课程相关：`/courses` - 获取课程列表
    - 教师相关：`/api/teacher/login`, `/api/teacher/register`, `/api/teacher/list`
    - 学生相关：`/api/students` (GET/POST), `/api/students/<id>`, `/api/students/<id>/abilities`
    - 训练相关：`/api/students/<id>/training-sessions`
    - 字典表：`/api/course-types`, `/api/ability-types`
    - 游戏相关：`/api/getSequencingImages`, `/api/getMatchingImages`, `/api/saveResult`
  - **WebSocket事件**：
    - `video_frame` - 视频帧转发
    - `show_image` - 显示图片事件
    - `play_resource` - 播放资源事件

### 2. 数据库模块

#### `database/models.py` - 数据模型
定义了8个主要数据表：

1. **Teacher（教师表）**
   - 存储教师账户信息（用户名、密码哈希、真实姓名等）

2. **Student（学生表）**
   - 存储学生基本信息（姓名、年龄、偏好、头像等）

3. **CourseType（课程类型字典表）**
   - 固定5类：命名、拟声、模仿、配对、排序

4. **Course（课程主表）**
   - 存储课程基本信息（标题、图标、音频路径等）

5. **CourseItem（课程项表）**
   - 存储每个课程的具体内容项（图片、音频、配置等）

6. **AbilityType（能力类型字典表）**
   - 固定6类：注意力、模仿、配对、排序、表达性语言、接收性语言

7. **TrainingSession（训练事件表）**
   - 记录一次完整的训练事件（日期、时间等）

8. **TrainingDetail（训练详情表）**
   - 记录某次训练中每种课程的训练量

9. **AbilityItem（能力项表）**
   - 记录每次训练后更新的每个能力项分数

#### 数据库初始化脚本
- `init_db.py` - 初始化数据库表结构，创建默认管理员账户
- `migrate_courses.py` - 将JSON格式的课程数据迁移到数据库
- `generate_sample_data.py` - 生成示例数据

### 3. 前端模块

#### 传统HTML/JS前端
- **templates/** - HTML模板
  - `child.html` - 儿童端界面
  - `server.html` - 服务器端界面
- **互动排序/配对**：`static/resources/interactive/sequencing.html`、`matching.html`（儿童端 iframe 加载；亦可经 `/sequencing`、`/matching` 重定向访问）

- **static/js/** - JavaScript逻辑
  - `child.js` - 儿童端功能（接收指令、显示内容）
  - `server.js` - 服务器端功能
  - `common.js` - 通用功能
  - `pose_estimator.js` - 姿态估计（用于模仿课程）
  - `pose_similarity.js` - 姿态相似度计算

#### React前端（teacher_frontend/）
- **技术栈**：React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **主要组件**：
  - `LoginPage` - 教师登录
  - `StudentInfoPage` - 学生信息管理（列表、详情、能力数据、训练记录）
  - `CourseSelectionPage` - 课程选择（支持评估模式和训练模式）
  - `ControlPage` - 训练控制页面（播放资源、控制儿童端）

### 4. 静态资源模块

#### 课程资源组织
- **audios/** - 音频文件
  - 按课程类型分类：`mimic/`, `naming/`
  - 包含：问题音频、表扬音频、提示音频

- **images/** - 图片文件
  - 按课程类型分类：`mimic/`, `naming/`, `matching/`
  - 排序游戏图片按类别分类：`count/`, `height/`, `length/`, `size/`

- **videos/** - 视频文件
  - 用于视频课程内容

- **interactive/** - 交互式游戏
  - HTML格式的互动游戏页面

## 三、系统架构

### 通信架构
```
教师端 (therapist)  ←→  WebSocket/SocketIO  ←→  服务器 (app.py)
                                              ↓
儿童端 (child)      ←→  WebSocket/SocketIO  ←→  服务器 (app.py)
```

### 数据流
1. **教师登录** → 验证账户 → 返回教师信息
2. **选择学生** → 查询学生信息 → 显示能力数据和训练记录
3. **选择课程** → 从数据库获取课程配置 → 显示课程列表
4. **开始训练** → 教师端发送控制指令 → 服务器转发 → 儿童端接收并执行
5. **训练完成** → 保存训练记录 → 更新能力数据 → 记录到数据库

## 六、开发说明

### 启动后端
```bash
python app.py
```
服务器运行在：`http://127.0.0.1:8080`

### 初始化数据库
```bash
python database/init_db.py
```

### 启动React前端
```bash
cd teacher_frontend
npm install
npm run dev
```

### 构建React前端
```bash
cd teacher_frontend
npm run build
```

## 九、项目特点

1. **模块化设计**：前后端分离，数据库独立
2. **实时通信**：WebSocket实现教师端和儿童端实时交互
3. **数据驱动**：课程配置从数据库读取，便于管理
4. **多端支持**：教师端、儿童端、服务器端
5. **PWA**：当前按普通网页运行
6. **现代化UI**：React前端使用现代UI组件库
