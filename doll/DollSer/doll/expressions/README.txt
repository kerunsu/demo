表情素材目录

把需要调试的表情文件直接放在此目录，然后在动作工作台的“序列表情”区域点击“刷新表情目录”。每个动作序列只选择一个表情，表情不属于单个舵机动作块。

待机表情请单独放入 `idle` 子目录。待机目录中的素材不会出现在动作表情下拉菜单中；没有播放动作时会自动循环显示。

支持格式：
- 图片：PNG、JPG、JPEG、WEBP、GIF
- 视频：MP4、WEBM、OGG、MOV、M4V

动作预设和导出的 JSON 会保存文件名、相对整个动作序列的时间偏移、显示时长和循环设置。把动作发给别人时，请同时发送 JSON 和它引用的表情文件；接收方把表情文件放进同名 expressions 目录即可。

选择视频表情后，工作台会读取视频真实时长，并只扩展统一播放时间轴来容纳表情。舵机序列时长以及动作块的开始、到位、保持和回位时间不会被修改。图片和 GIF 使用界面中填写的显示时长。
